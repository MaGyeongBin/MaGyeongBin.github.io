## Introduction

- Object-centric representations는 visual reasoning, structured environment modeling, multi-agent modeling, 그리고 interacting physical systems의 simulation과 같은 다양한 application domain에서 machine learning 알고리즘의 sample efficiency와 generalization을 향상시킬 수 있는 잠재력을 가진다.
- 그러나 image나 video와 같은 raw perceptual input으로부터 object-centric representations를 얻는 것은 매우 challenging한 문제이며, 일반적으로 supervision을 필요로 하거나 task-specific architecture에 의존하는 경우가 많다. 이러한 이유로 실제 많은 모델들은 object-centric representation을 학습하는 단계를 생략하고, 대신 simulator나 game engine의 internal representation과 같이 이미 structured된 representation 위에서 directly 학습을 수행하는 경우가 많다.
- 이러한 한계를 극복하기 위해, 본 논문에서는 perceptual representation(예: convolutional neural network의 output)과 slots라 불리는 변수들의 집합 사이를 연결하는 differentiable interface인 **Slot Attention module**을 제안한다. Slot Attention은 iterative attention mechanism을 통해 입력으로부터 permutation symmetry를 가지는 output vector들의 집합을 생성한다.
- Capsule Networks에서 사용되는 capsules과 달리, Slot Attention에서 생성된 slots는 특정 object type이나 class에 specialization되지 않는다. 이러한 specialization은 오히려 generalization을 저해할 수 있기 때문이다. 대신, slots는 object files와 유사하게 동작하며, 공통된 representational format을 공유한다. 즉, 각 slot은 입력에 존재하는 어떤 object에도 binding될 수 있으며, 이러한 특성은 unseen compositions, 더 많은 objects, 그리고 더 많은 slots에 대해 systematic하게 generalization할 수 있도록 한다.
- Slot Attention은 간단하고 구현이 용이한 architectural component로, CNN encoder 위에 쉽게 결합될 수 있으며, image로부터 object representation을 추출하는 데 사용될 수 있다. 또한 이 모듈은 downstream task와 함께 end-to-end로 학습될 수 있다. 본 논문에서는 Slot Attention의 versatility를 보여주기 위해 두 가지 대표적인 downstream task를 고려한다. 하나는 unsupervised object discovery를 위한 image reconstruction task이고, 다른 하나는 set-structured object property prediction을 위한 supervised task이다.
    
    ### Contributions
    
    1. Slot Attention module을 제안한다. 이는 perceptual representation(CNN output 등)과 set-structured representation 사이를 연결하는 간단하면서도 효과적인 architectural component이다.
    2. Slot Attention 기반 architecture를 unsupervised object discovery task에 적용하여, 기존 state-of-the-art 방법들과 비교했을 때 동등하거나 더 우수한 성능을 보이면서도, 메모리 효율성과 학습 속도 측면에서 큰 개선을 달성하였다.
    3. Slot Attention module이 supervised object property prediction task에도 효과적으로 적용될 수 있음을 보였으며, 이 경우 attention mechanism은 object segmentation에 대한 direct supervision 없이도 각 object를 구분하여 highlight하는 능력을 학습할 수 있음을 확인하였다.

### Slot Attention Module

![image.png](/assets/img/2026-04-20-oc/image%201.png)

- Slot Attention module은 N개의 input feature vector 집합으로부터 K개의 output vector 집합으로 매핑하는 구조이며, 이 output vector들을 slots라고 부른다. output set의 각 vector는 입력에 존재하는 object 또는 entity를 설명할 수 있다. 전체 module은 pseudo-code 형태로 정의된다.
- Slot Attention은 iterative attention mechanism을 사용하여 input으로부터 slots로 매핑을 수행한다. slots는 초기에는 random하게 초기화되며, 이후 각 iteration마다 refinement 과정을 거쳐 input feature $\text{inputs} \in \mathbb{R}^{N\times D_{\text{inputs}}}$ 의 특정 부분 또는 grouping에 binding되도록 업데이트된다.
- 초기 slot representation을 공통된 distribution으로부터 random sampling하는 방식은 test time에 서로 다른 개수의 slots로도 generalization할 수 있도록 한다.
- 각 iteration에서 slots는 softmax 기반 attention mechanism을 통해 input의 일부를 설명하기 위해 서로 경쟁하며, 이후 recurrent update function을 통해 자신의 representation을 업데이트한다. 최종적으로 각 slot에 저장된 representation은 unsupervised object discovery 또는 supervised set prediction과 같은 downstream task에 활용될 수 있다.
- 하나의 iteration을 구체적으로 보면, 입력은 N개의 feature vector로 구성되며, 출력은 K개의 slot vector로 구성된다. attention 계산을 위해 learnable linear transformation인 k, q, v를 사용하여 inputs와 slots를 공통 embedding dimension으로 mapping한다.
- Slot Attention은 dot-product attention을 사용하며, attention coefficient는 inputs 방향이 아니라 slots 방향으로 normalization된다. 즉, 각 input feature가 어떤 slot에 할당되는지를 결정하는 구조이며, 이 normalization 방식은 slots 간의 competition을 유도한다.
    
    $$
    \text{attn}_{i,j} := \frac{e^{M_{i,j}}}{\sum_l e^{M_{i,l}}} \quad \text{where} \quad M := \frac{1}{\sqrt{D}} k(\text{inputs}) \cdot q(\text{slots})^T \in \mathbb{R}^{N \times K}
    $$
    
- attention coefficient는 각 input feature vector에 대해 합이 1이 되도록 normalization되며, 이는 attention mechanism이 input의 일부를 무시하지 못하도록 만든다.
- 이후 input value를 slot으로 aggregate하기 위해 weighted mean을 사용한다. 이는 attention coefficient가 slots 방향으로 normalization되어 있기 때문에, 단순 weighted sum보다 더 안정적인 학습을 가능하게 한다. 또한 numerical instability를 방지하기 위해 attention coefficient에 작은 값을 추가한다.
- 이렇게 계산된 aggregated update는 각 slot의 representation을 업데이트하는 데 사용된다. 이를 위해 Gated Recurrent Unit (GRU)를 사용하며, GRU는 각 slot에 대해 독립적으로 적용된다. 이후 선택적으로 residual connection이 포함된 multi-layer perceptron (MLP)을 적용하여 성능을 향상시킬 수 있다. GRU와 MLP는 모든 slot에 대해 shared parameter를 사용한다.
- Layer Normalization은 입력 feature와 slot feature에 대해 각각 적용되며, 각 iteration의 시작 시점과 residual MLP 적용 이전에 사용된다. 이는 필수 요소는 아니지만 training convergence를 빠르게 하는 데 도움을 준다.
- 전체 module의 시간 복잡도는 iteration 수, embedding dimension, input feature 수, slot 수에 비례한다. $\text{O}(T\cdot D \cdot N \cdot K)$.
- Slot Attention은 두 가지 중요한 성질을 가진다:
    1. Permutation invariance (input에 대해)
        
        입력 feature의 순서를 변경하더라도 출력은 동일하다. 따라서 set 형태의 입력에 적합하다.
        
    2. Permutation equivariance (slot에 대해)
        
        slot의 순서를 permutation하면 출력도 동일하게 permutation된다. 즉, slot의 순서는 의미를 가지지 않으며 interchangeable하다.
        
- 이러한 성질은 모든 slot이 동일한 representational format을 공유하고, 어떤 slot이든 입력의 어떤 object에도 binding될 수 있도록 하는 데 중요한 역할을 한다.
    
    $$
    \operatorname{SlotAttention}(\pi_i \cdot \text{inputs}, \pi_s \cdot \text{slots}) = \pi_s \cdot \operatorname{SlotAttention}(\text{inputs}, \text{slots})
    $$
    
    - $\text{SlotAttention} \in \mathbb{R}^{K\times D_{slots}}$
    - $\text{inputs} \in \mathbb R^{N\times D_{inputs}}$ and $\text{slots}\in \mathbb{R}^{K\times D_{slots}}$.
    - $\pi_i \in \mathbb R^{N\times N}$ and $\pi_s \in \mathbb R^{K\times K}$.

### Object Discovery

- Set-structured hidden representation은 object에 대한 정보를 unsupervised 방식으로 학습하는 데 있어 매력적인 선택지이다.
- 각 set element는 scene에 존재하는 object의 properties를 표현할 수 있으며, object들이 어떤 순서로 표현되는지에 대한 가정을 필요로 하지 않는다.
- Slot Attention은 input representation을 vector들의 집합으로 변환하기 때문에, unsupervised object discovery를 위한 autoencoder architecture의 encoder 구성 요소로 사용될 수 있다.
- 이 autoencoder는 이미지를 set 형태의 hidden representation(즉, slots)으로 encoding하고, 이 slot들을 다시 image space로 decoding하여 원본 입력을 reconstruction하는 것을 목표로 한다.
- 이 과정에서 slots는 representational bottleneck으로 작용하며, decoder 구조는 일반적으로 각 slot이 이미지의 특정 region 또는 부분만을 복원하도록 설계된다. 이후 이러한 부분적인 reconstruction들이 결합되어 최종 이미지가 생성된다.
- Encoder는 두 가지 구성 요소로 이루어진다:
    1. positional embedding이 추가된 CNN backbone
    2. Slot Attention module
- 각 slot은 개별적으로 decoding되며, 이를 위해 IODINE에서 사용된 것과 동일한 spatial broadcast decoder를 사용한다.
- 각 slot representation은 2D grid 형태로 broadcast되며, 여기에 positional embedding이 추가된다. 이렇게 생성된 grid는 shared parameter를 가지는 CNN을 통해 decoding된다.
- 각 slot은 W × H × 4 크기의 output을 생성하며, 이 output은 다음을 포함한다:
    - RGB color (3 channels)
    - unnormalized alpha mask (1 channel)
- 이후 각 slot에서 생성된 alpha mask는 softmax를 통해 normalization되며, 이를 mixture weight로 사용하여 각 slot의 reconstruction을 결합한다. 최종적으로 이 결합된 결과가 하나의 RGB 이미지로 생성된다.

### Set Prediction

- Set representation은 다양한 데이터 모달리티에서 사용되며, point cloud prediction, 이미지 내 다중 객체 분류, 분자 생성 등 여러 task에 적용된다.
- 이 논문에서 고려하는 예시는 입력 이미지가 주어졌을 때, scene에 존재하는 각 object를 설명하는 target들의 집합을 예측하는 문제이다.
- Set prediction에서의 핵심 문제는 set의 순서가 정의되어 있지 않다는 점이다.
- 즉, K개의 element를 가지는 set은 K!개의 동일한 표현이 존재할 수 있다.
- 이러한 permutation ambiguity는 학습 과정에서 불연속성을 유발할 수 있으며, 예를 들어 두 개의 slot이 학습 도중 서로의 역할을 바꾸는 현상이 발생할 수 있다.
- Slot Attention은 이러한 문제를 해결하는 데 적합하다. Slot Attention의 output은 순서에 의존하지 않으며, slot의 순서는 입력과 무관하게 결정된다. 따라서 permutation symmetry를 자연스럽게 만족하며, set prediction 문제에 적합한 구조를 제공한다.
- 각 slot에 대해 shared parameter를 가지는 MLP를 적용하여 object의 속성을 예측한다. 모든 slot은 동일한 classifier를 공유하며, 각 slot이 하나의 object를 담당하도록 학습된다.
- 예측된 slot들과 ground truth label 간의 순서는 서로 대응되지 않기 때문에, 이를 해결하기 위해 Hungarian algorithm을 사용하여 optimal matching을 수행한다.
- 이를 통해 예측 결과와 정답 간의 permutation 문제를 해결하고, 올바른 correspondence를 기반으로 loss를 계산할 수 있다.

## Experiments

- object-centric task supervised, Slot Attention module을 unsupervised를 평가한다.
- **Datasets**
    - unsupervised object property prediction에서는 Deep Set Prediction Networks (DSPN) [31]과 비교한다. DSPN은 우리가 알고 있는 한, 제안된 모델을 제외하고 permutation symmetry를 만족하는 유일한 set prediction 모델이다.
    - 두 task 모두에서, 우리는 Slot MLP라고 부르는 간단한 MLP 기반 baseline과도 비교한다. 이 모델은 Slot Attention을, CNN feature map(리사이즈 및 flatten된 형태)으로부터 (이제는 순서가 있는) slot representation으로 매핑하는 MLP로 대체한다.
    - MONet, IODINE, DSPN baseline에 대해서는, 동일한 experimental setup을 사용하기 때문에 [16, 31]에 보고된 published 성능 수치를 그대로 비교에 사용한다.

## Conclusion

- 우리는 low-level perceptual input으로부터 object-centric abstract representation을 학습할 수 있는 범용적인 architectural component인 **Slot Attention module**을 제안하였다. Slot Attention에서 사용되는 iterative attention mechanism은 모델이 input feature를 slot representation의 집합으로 분해하는 grouping strategy를 학습할 수 있도록 한다.
- Unsupervised visual scene decomposition과 supervised object property prediction에 대한 실험을 통해, Slot Attention이 기존의 관련 방법들과 비교했을 때 매우 경쟁력 있는 성능을 보이면서도, memory consumption과 computation 측면에서 더 효율적임을 보였다.
- 향후 연구로는 Slot Attention을 video data나 다른 데이터 modality에 적용하는 것이 자연스러운 다음 단계이다. 예를 들어, graph에서 node clustering, point cloud processing backbone 위에서의 적용, 또는 textual이나 speech data에의 적용 등이 가능하다. 또한 reward prediction, visual reasoning, control, planning과 같은 다양한 downstream task에의 적용 역시 유망한 방향이다.

## Broader Impact

- Slot Attention module은 perceptual input으로부터 object-centric representation을 학습할 수 있도록 한다. 따라서 이는 다양한 domain과 application에서 활용될 수 있는 일반적인 모듈이다.
- 본 논문에서는 slot이 object에 특화되도록 설계된, 잘 통제된 artificial dataset만을 고려하였다. 그러나 모델의 specialization은 명시적으로 강제된 것이 아니라, 전적으로 downstream task에 의해 암묵적으로 결정된다.
- 모듈이 원하지 않는 방식으로 specialization되었는지를 평가하기 위한 구체적인 방법으로, attention mask를 시각화하여 input feature가 각 slot에 어떻게 분배되는지를 확인할 수 있다 (Figure 6 참조).
- 입력 feature가 사람이 해석하기 어려운 경우, attention coefficient가 모델의 전체 prediction을 설명하는 데 얼마나 유용한지에 대해서는 추가적인 연구가 필요하다. 그럼에도 불구하고, 이러한 attention 기반 표현은 보다 투명하고 해석 가능한 예측으로 나아가는 하나의 단계가 될 수 있다고 본다.
