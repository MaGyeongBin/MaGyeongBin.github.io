## Introduction

- Vision Transformers (ViTs)는 내부 연산 과정에서 high-norm tokens가 생성되는 현상을 보인다. 이러한 outlier tokens는:
    - low-information regions (예: uniform background patches)에서 나타나며
    - global information을 저장하고 전달하는 역할을 수행하고
    - 결과적으로 noisy attention maps를 유발하여 downstream visual task 성능을 저하시킨다
- 기존 연구(Darcet et al., 2024)는 이를 해결하기 위해 **register tokens**를 도입하였다.
- 이 방법은 입력 시퀀스에 additional non-image tokens를 추가하여:
    - patch tokens는 local content encoding에 집중하도록 하고
    - register tokens는 global information 저장을 담당하도록 한다
- 하지만 이 방식은 기존 모델을 **retraining from scratch**해야 한다는 한계가 있다.
- 본 논문에서는 다음을 주장한다:
    - register는 유용하지만
    - 반드시 학습될 필요는 없다
- 따라서, test-time에서 register를 추가하는 training-free 방법을 제안한다.
- 이를 위해 high-norm token이 생성되는 메커니즘을 분석하고, 해당 현상을 제어할 수 있는 방법을 제시한다.

## Interpreting the outlier tokens mechanism in ViTs

### How do outliers emerge in ViTs?

- outlier tokens는 **attention block 이후가 아니라 MLP 이후**에서 나타남
- 즉, MLP가 특정 token의 norm을 증가시키는 주요 원인이다.
- 특정 layer에서 norm이 급격히 증가하며
- 이후 attention layer에서 해당 token이 attention sink로 작용한다
- outlier tokens는 **low-information regions**에서 발생
- local information은 사라지고
- global image-level information을 담게 된다

---

### Register neurons

- 논문에서는 high-norm token 생성의 원인을 register neurons라는 개념으로 설명한다.
- register neurons = outlier token 위치에서 consistently 높은 activation을 보이는 neuron
    - 매우 sparse하게 활성화됨
    - 특정 spatial 위치에 종속되지 않음
    - outlier token의 위치를 결정하는 역할 수행

→register neuron activation pattern → outlier token 위치 결정

---

### Detecting register neurons

- register neurons는 1)여러 이미지에 대해 outlier token 위치를 먼저 찾고 2) 해당 위치에서 activation이 높은 neuron을 선택 하는 방식으로 탐색

→“outlier를 만드는 neuron”을 역으로 찾는 과정

---

### Moving outliers with register neurons

- register neurons를 이용하면 outlier token을 임의의 위치로 이동시킬 수 있다.
    1. 각 register neuron에 대해 가장 큰 activation 값을 선택
    2. 이를 원하는 token 위치로 복사
    3. 나머지 위치는 zeroing
- 결과:
    - 특정 patch를 **artificial attention sink**로 생성 가능
    - 즉, outlier token의 위치를 직접 제어할 수 있음

---

## Adding registers at test-time

### Moving outliers to added tokens

- 핵심 아이디어:
    - outlier를 image patch가 아니라 추가된 token (test-time register)로 이동
    - outlier token은 local information을 잃기 때문에
    - image 내부에 존재하면 downstream task에 악영향을 줌
- 방법
    1. 입력 시퀀스에 additional token 추가
    2. register neuron activation을 해당 token으로 이동
    3. 기존 patch에서는 activation 제거
    4. forward pass 계속 진행
- 결과
    - image patch에서는 outlier 제거
    - register token이 high-norm을 흡수

---

### Test-time register initialization

- 추가되는 register token은 **zero vector**로 초기화
- initialization 방식은 성능에 큰 영향 없음
- 하나의 register token만으로도 충분한 효과 확인

---

### Outliers move outside the image after adding test-time registers

- test-time register를 적용하면:
    - image patch에서는 high-norm token이 사라지고
    - register token이 해당 역할을 대신 수행
- 결과:
    - attention map에서 artifact 제거
    - cleaner attention visualization 생성
- test-time register는 global information을 저장하는 역할을 수행하며
- trained register와 유사한 성능을 보인다

---

## Discussion, limitations, and future work

- 우리는 ViTs에서 발생하는 간단한 emergent mechanism을 발견하였다. 이는 low-information image locations에서 high-norm tokens를 생성하는 역할을 하는 sparse set of neurons이다.
- 이 메커니즘을 test-time에서 조작함으로써, high-norm을 추가된 register로 이동시킬 수 있었고, 그 결과 patch에서의 artifact를 제거하고 더 interpretable feature maps를 얻을 수 있었다. 동시에 downstream performance는 유지되거나 소폭 향상되었다. 이후 우리는 분석의 한계와 향후 연구 방향을 논의한다.
- 저자의 분석은 high-norm token의 위치를 제어할 수 있음을 보여주지만, 우리는 그 생성 원인 중 단 하나의 구성 요소인 neurons에만 초점을 맞췄다. attention layers나 positional encodings와 같이 outlier 생성에 기여할 수 있는 다른 요소들은 고려하지 않았다.
- 또한, 저자가 조작한 token은 learned counterpart와 비교했을 때 약간의 성능 차이를 보였으며, 이는 test-time registers가 high-norm tokens와 완전히 동일하지는 않음을 시사한다.
- 추가로, Darcet et al. (2024)와 유사하게, 저자들은 주로 특정 모델들(CLIP, DINOv2)에 집중.
- 우리가 발견한 메커니즘은 model neuron에 대한 흥미로운 특성을 시사
    - 모든 neuron이 feature와 직접적으로 관련된 역할을 수행하는 것은 아니다.
    - 예를 들어, register neurons는 high-norm token을 생성하는 역할을 수행하며, 이는 image-independent role이다.
    - 따라서 이러한 neuron은 activation과 image feature 간의 상관관계를 통해서는 발견될 수 없다.
- 또한, 유사한 high-norm tokens는 language model에서도 관찰된 바 있으며 , 이는 large language models에서도 유사한 메커니즘이 존재할 가능성을 시사.
- 이처럼 input-independent 역할을 수행하는 neuron을 더 많이 밝혀내는 것은 deep neural network의 computational process를 이해하는 데 중요한 단서를 제공. 향후 연구에서는 이러한 neuron을 자동으로 탐지하는 방법론을 개발할 계획
