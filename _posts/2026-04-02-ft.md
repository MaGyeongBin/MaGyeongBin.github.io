- 현재 페이지는 신호및처리시스템 관점이 아닌 컴퓨터비전 관점에서 정리한 Fourier Transform을 공부한 내용. 같은 내용이나, 중점적으로 공부하려는 단원이 다름.

## 정의

- 신호를 각 주파수 방향으로 projection 하는것.
    
    $$
    F(\omega) = \int_{-\infty}^{\infty} f(t)\, e^{-i\omega t}\, dt
    
    $$
    
    $$
    f(t) = \frac{1}{2\pi} \int_{-\infty}^{\infty} F(\omega)\, e^{i\omega t}\, d\omega
    $$
    
    - $e^{-iwt} :$ sin + cos
    - 따라서 $F(\omega) = \int_{-\infty}^{\infty} f(t)\, (진동) , dt$
    : 신호 $f(t)$ 가 특정 주파수 $w$ 와 얼마나 비슷한지 측정.
    - 신호를 각 주파수 방향으로 projection 하는것.
- 즉, Fourier Transform = 신호를 주파수 별로 분해해서, 각 주파수 성분의 크기와 위상을 구하는 연산.

## GNN에서의 Fourier Transform

- 그래프에서는 $e^{jwt}$ 대신 eigenvector $U$ 를 사용한다.
    - 일반 Fourier: 주기함수로 정의가능(sin, cos)
    - 그러나 그래프는, 노드들이 불규칙하게 연결(주기X)
- 따라서 그래프 구조를 반영하는 행렬을 사용.
    
    $$
    L = D-A \ \ \ \ \ \ \ \  or \ \ \ \ \ \ L = I-D^{-1/2}AD{-1/2}
    $$
    
    - $U:$  eigenvector
    - $\Lambda :$ eigenvalue
- 그래프 Fourier: $\hat x = U^Tx$
    - $x:$  노드 신호
    - $U$: basis (sin, cos)
    - $U^Tx$: projection
- eigenvector는 그래프 위에서의 진동 방향을 의미함. (eigenvector가 진동을 의미하는 이유는 Graph Laplacian이 차이를 측정하는 연산자이기 때문.)
- 높은 eigenvalue → high frequency
- 낮은 eigenvalue → low frequency
- $g_\theta * x = U g_\theta(\Lambda) U^T x$
    - $U^Tx$  → 주파수 영역으로 변환.
    - $g_\theta(\Lambda)$ → 필터 적용.
    - $U$ → 다시 원래 공간으로 복원.
