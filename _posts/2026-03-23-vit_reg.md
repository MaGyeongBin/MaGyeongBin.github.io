## Introduction

- 이미지를 다양한 컴퓨터 비전 작업에 활용 가능한 일반적인 feature로 임베딩하는 문제는 오랫동안 연구되어 왔다. 초기에는 SIFT와 같은 수작업 기반 방법이 사용되었지만, 데이터 규모 증가와 딥러닝 기술 발전으로 end-to-end 학습이 가능해졌다.
- 그럼에도 불구하고 일반적인 feature embedding의 필요성은 여전히 존재한다. 이는 많은 특정 작업에서 고품질의 주석 데이터 확보가 어렵기 때문이다. 예를 들어 의료 데이터나 원격 탐사 데이터는 전문 지식이 필요하며, 대규모 데이터 구축에는 높은 비용이 든다.
- 현재는 데이터가 풍부한 작업에서 모델을 사전 학습한 후, 해당 모델의 일부를 feature extractor로 사용하는 방식이 일반적이다. 이러한 접근에는 지도 학습 기반 방법과 자기 지도 학습 기반 방법이 포함된다.
- 특히 Transformer 기반 자기 지도 학습 방법은 downstream task에서 높은 성능과 함께, 일부 모델이 비지도 방식으로 segmentation을 수행할 수 있다는 점에서 주목받고 있다.
- DINO 알고리즘은 이미지의 semantic 구조를 명시적으로 반영하는 모델을 생성하는 것으로 알려져 있다. 실제로 마지막 attention layer는 이미지의 의미적으로 일관된 영역에 집중하며, 해석 가능한 attention map을 생성한다. 이러한 특성을 활용하여 LOST와 같은 객체 탐지 알고리즘이 제안되었으며, 이는 supervision 없이도 객체를 탐지할 수 있게 한다.
- DINOv2는 이러한 DINO의 후속 모델로, dense prediction task에서도 높은 성능을 보인다. 그러나 DINOv2는 LOST와 같은 방법과 결합 시 기대보다 낮은 성능을 보인다. 이는 DINOv2의 feature map에 이전 버전에는 없던 아티팩트가 존재하기 때문임을 확인하였다.
- 더 나아가, 이러한 아티팩트는 DINOv2뿐 아니라 일반적인 Vision Transformer에서도 나타난다. 이는 DINO가 오히려 예외적인 경우이며, 대부분의 ViT는 기본적으로 이러한 현상을 가진다는 것을 의미한다.
- 본 연구에서는 이 현상을 이해하고 탐지하는 방법을 제시한다. 우리는 다음과 같은 관찰을 얻었다:
    - 전체 토큰 중 약 2%만이 매우 높은 norm을 가짐
    - 이 토큰들은 중간 레이어에서 등장
    - 충분히 큰 모델과 긴 학습 이후에만 발생
    - 정보가 거의 없는 패치 영역에서 나타남
- 또한 분석 결과:
    - 이 토큰들은 local 정보(위치, 픽셀 정보)를 거의 보존하지 않음
    - 대신 global 정보는 많이 포함함
- 이를 통해 우리는 다음과 같은 해석을 제시한다:
    
    > 모델은 정보량이 낮은 패치를 감지하고, 해당 토큰을 재활용하여 global 정보를 저장하는 역할로 사용한다.
    > 
    
    이 가설을 검증하기 위해, 입력 이미지와 무관한 추가 토큰(register token)을 삽입하였다. 그 결과:
    
    - outlier 토큰이 완전히 사라짐
    - dense prediction 성능 향상
    - feature map이 더 부드러워짐
    - object discovery 성능 향상

## Problem Formulation

- 현대 Vision Transformer는 attention map에서 아티팩트를 보인다. 특히 DINOv2는 좋은 local feature를 가지면서도 undesirable artifact를 포함한다.

### Artifacts in Local Features of DINOv2

- 아티팩트는 high-norm outlier 토큰으로 정의된다.
- 관찰 결과:
    - 일반 토큰 대비 훨씬 높은 L2 norm
    - 분포가 bimodal 형태
    - threshold (예: norm > 150)로 구분 가능

### Outlier 특성

1. **훈련 중 발생 조건**
    - 중간 레이어 이후 등장
    - 학습 후반부에서 생성
    - 큰 모델에서만 발생
2. **위치 특성**
    - 주변 패치와 유사한 영역 (low-information 영역)
    - 주로 background에서 등장
3. **정보 특성**
    - 위치 정보 예측 성능 낮음
    - 픽셀 복원 성능 낮음
    → local 정보 거의 없음
4. **Global 정보**
    - classification 성능 높음
    → global representation 저장 역할 수행

### Hypothesis

![image.png](/assets/img/2026-03-23-vit_reg/image.png)

- 모델은 다음과 같이 동작한다:
    - 정보가 적은 패치를 감지
    - 해당 토큰을 global 정보 저장용으로 재사용
    - 대신 local 정보는 버림
- 이 과정이 patch token 내부에서 발생하기 때문에 문제가 된다.

### Remediation

- 우리는 다음 방법을 제안한다:
    - 입력 시퀀스에 **register token 추가**
    - patch embedding 이후 삽입
    - 출력에서는 사용하지 않음
    
    효과:
    
    - outlier 토큰 제거
    - feature map 개선
    - downstream 성능 향상

## Conclusion

- 본 연구에서는 DINOv2 및 다양한 Vision Transformer에서 나타나는 feature map 아티팩트를 분석하였다.

주요 발견:

- 아티팩트는 high-norm 토큰 형태로 나타남
- 모델은 low-information 패치를 재활용하여 global 정보 저장에 사용함

우리는 이를 해결하기 위해 register token을 도입하였으며:

- 아티팩트를 완전히 제거
- dense prediction 성능 향상
- object discovery 성능 개선
- 또한 이 방법은 self-supervised뿐 아니라 supervised 모델에서도 동일하게 효과를 보였다.

→따라서 본 연구는 Vision Transformer의 내부 동작을 이해하고, 구조적으로 개선할 수 있는 단순하면서도 일반적인 방법을 제시한다.
