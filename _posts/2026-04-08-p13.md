## Introduction

- 최근 연구에 따르면 language model은 reinforcement learning을 통해 reasoning 능력을 학습할 수 있다.
- 일부 연구에서는 reasoning을 위해 low-rank parameterization을 학습하기도 하지만, 기존 LoRA는 model dimension 이하로 scaling하는 데 한계가 있다.
- 본 논문에서는 rank=1 LoRA조차 reasoning 학습에 반드시 필요한지 의문을 제기하며, 단 하나의 parameter까지 축소 가능한 TinyLoRA를 제안한다.
- 새로운 parameterization을 통해, Qwen2.5 8B 모델을 단 13개의 parameter만 학습하여 GSM8K에서 91% accuracy를 달성할 수 있음을 보였다.
- 또한 이러한 경향은 일반적으로 유지되며, AIME, AMC, MATH500과 같은 더 어려운 reasoning benchmark에서도 약 1000배 적은 parameter로도 90% 이상의 성능 향상을 유지할 수 있었다.
- 특히 중요한 점은, 이러한 성능은 reinforcement learning(RL)에서만 가능하며 supervised finetuning(SFT)에서는 동일 성능을 위해 100~1000배 더 많은 parameter가 필요하다는 것이다.
- modern language model은 reasoning을 위해 추가적인 thinking token을 생성하도록 reinforcement learning (RLVR)으로 post-training된다. reasoning 학습은 주로 math나 coding과 같은 검증 가능한 task에서 수행된다.
- 기존에는 수십억 parameter를 가진 모델 전체를 finetuning하는 것이 일반적이었지만, LoRA와 같은 parameter-efficient 방법은 이를 수백만 parameter 수준으로 줄였다. 하지만 여전히 update 규모는 크다. 예를 들어 LLaMA3-8B 모델에서 rank=1 LoRA조차 약 3M parameter를 학습해야 한다.
- parameter 수를 줄이는 것은 여러 장점을 가진다:
    - GPU memory 사용 감소
    - distributed training communication cost 감소
    - inference 시 더 많은 LoRA를 동시에 유지 가능
    - catastrophic forgetting 완화
- 이러한 장점에도 불구하고, 우리는 더 극단적인 parameter efficiency가 가능한지 탐구한다.
- 본 논문은 다음과 같은 관찰을 기반으로 한다:
    - SFT는 많은 정보를 모델에 저장해야 한다
    - RL은 훨씬 적은 정보로도 학습이 가능하다
- 따라서 RL 기반 학습은 훨씬 작은 parameter update로도 동일한 성능을 낼 수 있다.

## Update Capacity of SFT and RL

- 본 섹션에서는 supervised finetuning(SFT)과 reinforcement learning(RL)의 학습 capacity를 비교한다.
- 모델 $\pi_\theta$는 입력 $x$를 받아 출력 $y$를 생성한다.
- SFT의 objective는 다음과 같다:
    - next-token prediction loss 기반: 전체 output sequence를 정확히 재현하도록 학습
    
    $$
    \mathcal{L}_{\text{SFT}}(\theta) = -\mathbb{E}_{(x,y) \sim (\mathcal{X}, \mathcal{Y})} \left[ \sum_{t=1}^{|y|} \log \pi_\theta (y_t | x, y_{<t}) \right]
    $$
    
- RL의 경우 policy gradient를 사용하며:
    - reward 기반 학습: output 전체가 아니라 reward signal만 사용
    
    $$
    \nabla_\theta J(\theta) = \mathbb{E}_{x \sim X; y \sim \pi_\theta} \left[ \sum_{t=1}^{|y|} \nabla_\theta \log \pi_\theta (y_t | x, y_{<t}) \cdot R(y) \right]
    $$
    

### Information Content 관점

- SFT:
    - (x, y) 전체를 학습
    - 모든 token이 동일하게 중요하게 취급됨
    - noise와 signal 구분 불가
- RL:
    - reward만이 중요한 정보
    - 나머지 output variation은 대부분 noise
    - reward 관련 정보만 학습됨
    
    → SFT는 많은 정보를 저장해야 함, RL은 핵심 정보만 학습
    

### Signal Separation

**RL**:

- reward와 관련된 feature만 축적됨
- noise는 반복 sampling 과정에서 상쇄됨

**SFT:**

- 어떤 feature가 중요한지 구분 불가능
- 모든 token을 동일하게 학습

### Hypothesis

- SFT는 low-parameter regime에서 성능이 낮은 이유:
    - 많은 정보(불필요한 정보 포함)를 저장해야 하기 때문
- RL은:
    - 정보가 sparse하지만 signal이 명확
    - 따라서 작은 parameter로도 학습 가능

## Parameter-Efficient Finetuning with TinyLoRA

- TinyLoRA는 LoRA를 극단적으로 축소한 형태이다.

### LoRA

- 기존 LoRA는 pretrained weight를 직접 수정하지 않고, low-rank update를 추가하는 방식이다.
- 기존 LoRA는 다음과 같이 weight를 업데이트한다:
- $W' = W +AB$
    - $W \in \mathbb{R}^{d\times k}$: flozen pretrained weight
    - $A \in \mathbb R ^{d \times r}$
    - $B \in \mathbb R ^{r \times k}$
    - $r$: rank
- 즉 $AB$ 는 rank $r$ 의 low-rank matrix로, 원래 weight $W$ 변화를 추가.
- parameter 수는 O(dr)

### LoRA-XS

- LoRA-XS는 $W$ 의 SVD 기반으로 다음과 같이 표현:
- $W' = WU\sum RV^T$
    - R만 학습됨 = 이미 존재하는 주요 singular direction $(U, V)$ 를 재조합. 즉, 이미 가진 주요한 성질을 활용.
    - parameter 수는 O(r²)

### TinyLoRA

- TinyLoRA는 R을 더 줄인다:
    - trainable vector $v \in \mathbb R^{u}$ 만 학습
    - fixed random tensor $P \in \mathbb R^{u\times r\times r}$로 projection
- $W' = W + U(\sum v_iP_i) V^T$
- 각 module당 u개의 parameter만 학습

### Parameter Sharing

- Transformer 구조에서는:
    - attention + MLP 포함 여러 module 존재
- TinyLoRA는:
    - 여러 module이 동일한 v를 공유하도록 weight tying 가능
- 결과:
    - 전체 parameter 수: $O(nmu/n_{tie})$
- 극단적인 경우:
    - 모든 module이 동일 parameter 공유 → 단 1개의 parameter만 학습 가능

## Discussion

- 본 연구는 다음과 같은 중요한 insight를 제공한다:

### Scaling Trend

- model size가 커질수록
- 필요한 update parameter 수는 감소
- large model일수록 더 적은 parameter로 제어 가능

### Why does this work?

- 필요한 지식은 이미 pretrained model 내부에 존재
- finetuning은:
    - 새로운 지식 학습이 아니라
    - output style 변경
- longer reasoning chain 생성 능력이 핵심

### Model Difference

- Qwen 모델은 작은 parameter update에서 매우 효율적
- LLaMA 대비 약 10배 적은 parameter로 동일 성능 달성
- architecture 차이
- pretraining 데이터 차이

## Experiments

### Design

- **GSM8K**: 약 7,500개의 math word problem으로 구성된 dataset
- **MATH**: 더 높은 난이도의 수학 문제 dataset (특히 hardest subset 사용)

### Training Methods

- Supervised Finetuning (SFT)
    - next-token prediction 기반
- Reinforcement Learning (RL)
    - Group Relative Policy Optimization (GRPO) 사용
    - exact-match reward 기반

### Evaluation

### Initial Low-Parameter Results

- 약 120 parameter만으로 full finetuning 대비 95% 성능 회복
- 단 1개의 parameter만 학습해도 약 4% 성능 향상
- TinyLoRA → LoRA-XS → LoRA로 갈수록
- parameter 증가에 따라 성능이 smooth하게 증가

### SFT vs RL

- RL: 13 parameter → 91%
- SFT: 13 parameter → 83%

### 결론

- RL은 low-parameter regime에서 매우 효율적
- SFT는 parameter가 충분히 많아야 성능 향상 가능

### Limitations

- 실험은 math reasoning에 한정됨
- 다른 domain(creative writing, science 등)에는 일반화 불확실

## Conclusion

- TinyLoRA는 매우 적은 parameter로도 효과적인 finetuning이 가능함을 보였다.
- 수십~수백 byte 수준의 update로도 높은 성능 달성 가능
- 일부 task에서는 13개의 parameter만으로도 reasoning 성능 향상
- RL은 매우 작은 capacity에서도 효과적으로 학습 가능
- 이는 기존의 “large update 필요”라는 가정을 깨는 결과
- reasoning 능력은 새롭게 학습되는 것이 아니라
- 기존 모델에 존재하는 능력을 활성화하는 것일 가능성이 있음
