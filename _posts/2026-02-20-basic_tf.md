## Transformer: Attention Is All You Need 공부

트랜스포머(Transformer)는 2017년 "Attention is All You Need" 논문에서 소개된 신경망 아키텍처로, 기존의 RNN이나 CNN에 의존하지 않고 오직 어텐션(Attention) 메커니즘만을 사용하여 자연어 처리 태스크를 해결합니다.

![image.png](/assets/img/2026-02-20-basic_tf/image.png)

### 주요 특징

- **인코더-디코더 구조:** 입력 시퀀스를 처리하는 인코더와 출력 시퀀스를 생성하는 디코더로 구성
- **셀프 어텐션(Self-Attention):** 시퀀스 내 모든 단어 간의 관계를 동시에 파악하는 메커니즘
- **멀티헤드 어텐션(Multi-Head Attention):** 여러 개의 어텐션을 병렬로 수행하여 다양한 관점에서 정보 추출
- **포지셔널 인코딩(Positional Encoding):** 시퀀스 내 위치 정보를 모델에 주입
- **병렬 처리:** RNN과 달리 모든 입력을 동시에 처리하여 학습 속도 향상

### 영향력

트랜스포머는 BERT, GPT, T5 등 현대 대규모 언어 모델의 기초가 되었으며, 자연어 처리 분야에 혁명적인 발전을 가져왔습니다. 번역, 요약, 질의응답, 텍스트 생성 등 다양한 태스크에서 뛰어난 성능을 보이고 있습니다.

## Encoder

### 1. Input Embedding

#### 1-1. Tokenizer

토크나이저(Tokenizer)는 자연어 텍스트를 모델이 처리할 수 있는 작은 단위로 분할하는 과정을 담당합니다. 트랜스포머 모델의 첫 단계로, 입력 텍스트를 효과적으로 처리하기 위한 중요한 전처리 과정입니다.

- **단어 분할:** 텍스트를 단어, 서브워드(subword) 또는 문자 수준으로 분할
- **주요 토크나이징 방법:**
    - WordPiece: BERT에서 사용, 자주 등장하는 단어 조합을 하나의 토큰으로 처리
    - BPE(Byte Pair Encoding): GPT 계열에서 사용, 빈도 기반으로 문자 조합을 병합
    - SentencePiece: 언어에 구애받지 않는 토크나이징, 공백도 학습 대상에 포함

- **특수 토큰:** [CLS], [SEP], [MASK], [PAD] 등 모델 학습과 추론에 필요한 특수 목적 토큰 추가
- **어휘 제한:** 일반적으로 수만에서 수십만 개의 토큰으로 제한된 어휘 사전 사용
- **OOV(Out-of-Vocabulary) 처리:** 사전에 없는 단어를 [UNK] 토큰이나 서브워드로 분해하여 처리

#### 1-2. Embedding

인코더는 텍스트를 입력받아 벡터로 표현하는 과정입니다. 트랜스포머 인코더의 첫 단계인 Input Embedding은 텍스트 토큰을 고정 크기의 벡터로 변환합니다.

- **단어 표현:** 각 단어나 서브워드 토큰을 d_model 차원의 임베딩 벡터로 변환
- **학습 가능한 파라미터:** 임베딩 매트릭스는 학습 과정에서 업데이트됨
- **통계적 의미 포착:** 유사한 의미/문맥의 단어들은 임베딩 공간에서 가까운 위치에 배치됨
- **차원:** 원래 논문에서는 d_model=512 사용
- **사전 크기:** 일반적으로 수만에서 수십만 단어를 포함하는 어휘 사전 사용

### 2. Positional Encoding

#### 2-1. Odd

$$
PE(pos, 2i+1) = \cos(\frac{pos}{10000^{2i/d_{model}}})
$$

#### 2-2. Even

$$

PE(pos, 2i) = \sin(\frac{pos} {10000^{2i/d_{model}}})
$$

## 3. Multi-Head Attention

### 3-1. Parameters

- d_model
    - 입력/출력 벡터의 차원수 (모델 전체에서 사용하는 임베딩 차원)
    - ex): Transformer에서 단어 하난를 표현할 때 d_model=512 라면 각 단어 벡터는 512 차원으로 표현.
    - 이 값은 attention 내부에서 Query, Key, Value로 변환 될때 기준 차원.
- num_heads
    - d_model/num_heads 차원의 작은 공간에서 어텐션을 학습
    - 다양한 관점에서 동시에 학습 가능
- ex): d_model=512, num_head=16일때, 각 head의 demention은 32(d_model / num_head)가 된다.

### 3-2. Query, Key, Value

- Query
    - 의미: 행에서 하고 싶은 질문
    - ex: d_model=512, num_head=16, 예시 문장: The cat sat on the mat → Query: (6,32)
    - n번째 행이 의미하는 바는 문장에서 n번째 단어가 다른 단어들로부터 어떤 정보를 얻으려 하는지를 의미한다. → n번째 단어가 다른 단어들을 바라보는 시각
- Key
    - 의미: 행에서 단어의 색인
    - ex: d_model=512, num_head=16, 예시 문장: The cat sat on the mat → Key: (6,32)
    - n번째 행이 의미하는 바는 n번째 단어의 특징
- Value
    - 의미: 행에서 단어가 실제로 제공하는 정보
    - Query-Key 유사도를 기반으로 가중합될 “정보 원천”
    - Key가 색인이라면 Value는 그 주소에 대응되는 실제 데이터
    - ex: d_model=512, num_head=16, 예시 문장: The cat sat on the mat → Value: (6,32)
    - 문장 내 n번째 단어가 가지고 있는 실제 의미/특징 벡터
- Score($S$)
    - 의미: Query와 Key의 유사도
        - $S_{ij}$ = i번째 단어가 문장을 바라보는 시각과 j번째 단어의 특징의 유사도
    - 계산 방법: Query와 Key의 내적을 수행하여 계산 (QK^T)
    - 스케일링: 내적 결과를 √d_k로 나누어 정규화 (d_k는 key 벡터의 차원)
    - 소프트맥스: 정규화된 점수에 소프트맥스 함수를 적용하여 확률 분포로 변환
    - 결과: 각 Key에 대한 가중치로 사용되어 Value 벡터의 가중합을 계산

### 4. FFN

Feed Forward Network은 Transformer 아키텍처에서 각 인코더와 디코더 레이어에 포함된 완전연결 신경망입니다. 어텐션 메커니즘 이후에 적용됩니다.

- **구조:** 일반적으로 두 개의 선형 변환과 그 사이의 활성화 함수(ReLU)로 구성
- **역할:** 어텐션으로 얻은 정보를 추가로 처리하고 비선형성 추가
- **수식:** FFN(x) = max(0, xW₁ + b₁)W₂ + b₂
- **차원:** 입력과 출력은 d_model 차원을 유지하지만, 내부 히든 레이어는 일반적으로 더 큰 차원(d_ff)을 가짐
- **위치별 적용:** 시퀀스의 각 위치에 독립적으로 동일하게 적용됨

### 5. Code

#### 5-1. Encoder Only

```python
import math
import torch
import torch.nn as nn
from transformers import AutoTokenizer

#1. Input Embedding
text = "The cat sat on the mat."

tokenizer = AutoTokenizer.from_pretrained("bert-base-uncased")

enc = tokenizer(text, add_special_tokens=True, return_tensors="pt")
input_ids = enc["input_ids"]

# 2. Positional Embedding
class Positional_Embedding(nn.Module):
    def __init__(self, d_model, max_len=10000):
        super().__init__()
        pe = torch.zeros(max_len, d_model)
        pos = torch.arange(0, max_len, dtype=torch.float).unsqueeze(1)

        even_indices = torch.arange(0, d_model, step=2).float()
        exponent = even_indices/d_model
        div_term = 1 / (10000 ** exponent)
        
        pe[:, 0::2] = torch.sin(pos * div_term)
        pe[:, 1::2] = torch.cos(pos * div_term)

        self.register_buffer("pe", pe.unsqueeze(0))  

    def forward(self, x):
        L = x.size(1)
        return x + self.pe[:, :L, :]

# 3.Multi Head Attention
class MultiHead_Attention(nn.Module):
    def __init__(self, d_model, num_heads):
        super().__init__()
        assert d_model % num_heads == 0, "d_model Error"

        self.d_k = d_model // num_heads

        self.w_q = nn.Linear(d_model, d_model) 
        self.w_k = nn.Linear(d_model, d_model) 
        self.w_v = nn.Linear(d_model, d_model) 
        self.w_o = nn.Linear(d_model, d_model)

    def _shape(self, x):
        B, L, D = x.size()
        x = x.view(B, L, -1, self.d_k) 
        return x.transpose(1, 2)
    
    def forward(self, x):
        identity = x

        Q = self.w_q(x) 
        K = self.w_k(x) 
        V = self.w_v(x) 

        q = self._shape(Q) 
        k = self._shape(K) 
        v = self._shape(V) 

        score = torch.matmul(q, k.transpose(-2, -1)) 
        scaled_score = score / math.sqrt(self.d_k)
        context = torch.matmul(torch.softmax(scaled_score, dim=-1), v) 

        context = context.transpose(1, 2).contiguous() 
        B, L, H, d_k = context.size()

        x = context.view(B, L, H*d_k) 

        x = self.w_o(x)

        x = x + identity

        return x

# FeedForward
class FeedForward(nn.Module):
    def __init__(self, d_model):
        super().__init__()
        d_ff = d_model * 4
        self.fc1 = nn.Linear(d_model, d_ff)
        self.ReLU = nn.ReLU()
        self.fc2 = nn.Linear(d_ff, d_model)

    def forward(self, x):
        identity = x

        x = self.fc1(x)
        x = self.ReLU(x)
        x = self.fc2(x)
        x = identity + x

        return x

class Encoder(nn.Module):
    def __init__(self, d_model):
        super().__init__()

        vocab_size = tokenizer.vocab_size
        self.Embedding = nn.Embedding(num_embeddings=vocab_size, embedding_dim=d_model) 
        self.Pos_Embedding = Positional_Embedding(d_model) 
        self.MHA = MultiHead_Attention(d_model, num_heads=16) 
        self.FFN = FeedForward(d_model)
        self.ln = nn.LayerNorm(d_model)

    def forward(self, x):
        x = self.Embedding(x)
        x = self.Pos_Embedding(x)
        x = self.MHA(x)
        x = self.ln(x)
        x = self.FFN(x)
        x = self.ln(x)

        return x

vocab_size = tokenizer.vocab_size
model = Encoder(d_model=512)

with torch.no_grad():
    out = model(input_ids) 
print("Encoder output:", out.shape)

```

# Decoder

# 1. Output Embedding

### 1-1. Input

- Encoder의 Output을 Multi-Head Attention에서 Key, Value 값으로 사용한다.
- y값을 오른쪽으로 shift한 후 입력으로 사용한다.
    - ex) [’나는’,  ‘행복합니다’, ‘.’, <EOS>] → [<Bos>, ’나는’,  ‘행복합니다’, ‘.’]

### 1-2. Output Embedding

- Input Embedding과 동일한 방식으로 진행된다.

## 2. Masked Multi-Head Attention

## 2-1. Masking

- 현재의 위치에서 미래의 정보를 차단한 상태로 학습을 하기위해서 정의됐다.
- Score를 구한 후 i 열에서 j(j > i) 열에 대한 정보를 차단한다. → n번째 단어가 n+1번째 단어를 예측하기 위해서 정답을 차단한다.

## 3. Cross Multi-Head Attention

- seq2seq 문제를 해결할때 원문의 정보를 참조하기 위해서 사용된다.
- Decoder Only 모델에서는 존재하지 않는다.
- Encoder 에서 나온 출력값을 Key, Value로 사용한다.
    - $S = QK^{T}$
        - X 정보와 y가 참조한 의 유사성

## 5. Code

### 5-1. Decoder Only

```python
import math, torch
import torch.nn as nn
import torch.nn.functional as F

# ---- Positional Encoding ----
class PositionalEncoding(nn.Module):
    def __init__(self, d_model, max_len=4096):
        super().__init__()
        pe = torch.zeros(max_len, d_model)
        pos = torch.arange(0, max_len).unsqueeze(1).float()
        div = 1.0 / (10000.0 ** (torch.arange(0, d_model, 2).float() / d_model))
        pe[:, 0::2] = torch.sin(pos * div)
        pe[:, 1::2] = torch.cos(pos * div)
        self.register_buffer("pe", pe.unsqueeze(0))  # (1, L, D)
    def forward(self, x):
        return x + self.pe[:, :x.size(1), :]

# ---- FeedForward ----
class FeedForward(nn.Module):
    def __init__(self, d_model, mult=4, dropout=0.1):
        super().__init__()
        self.fc1 = nn.Linear(d_model, mult*d_model)
        self.fc2 = nn.Linear(mult*d_model, d_model)
        self.drop = nn.Dropout(dropout)
    def forward(self, x):
        return self.fc2(self.drop(F.relu(self.fc1(x))))

# ---- Masked Multi-Head Self-Attention ----
class SelfAttention(nn.Module):
    def __init__(self, d_model, n_heads, dropout=0.1, bias=True):
        super().__init__()
        assert d_model % n_heads == 0
        self.h  = n_heads
        self.dk = d_model // n_heads
        self.wq = nn.Linear(d_model, d_model, bias=bias)
        self.wk = nn.Linear(d_model, d_model, bias=bias)
        self.wv = nn.Linear(d_model, d_model, bias=bias)
        self.wo = nn.Linear(d_model, d_model, bias=bias)
        self.drop = nn.Dropout(dropout)

    def _split(self, x):  # (B,L,D)->(B,H,L,d)
        B, L, D = x.size()
        return x.view(B, L, self.h, self.dk).transpose(1,2).contiguous()

    def forward(self, x, attn_mask=None):  # x: (B,L,D), attn_mask: (B,L) where 1=token,0=pad
        B, L, _ = x.size()
        q = self._split(self.wq(x)); k = self._split(self.wk(x)); v = self._split(self.wv(x))  # (B,H,L,d)
        scores = torch.matmul(q, k.transpose(-2, -1)) / math.sqrt(self.dk)                      # (B,H,L,L)

        causal = torch.ones(L, L, device=x.device, dtype=torch.bool).triu(1)                    # (L,L)
        scores = scores.masked_fill(causal, float('-inf'))

        if attn_mask is not None:
            # key 위치 패딩 가리기
            key_pad = (attn_mask == 0).unsqueeze(1).unsqueeze(1)                                # (B,1,1,L)
            scores = scores.masked_fill(key_pad, float('-inf'))

        attn = F.softmax(scores, dim=-1)
        attn = self.drop(attn)
        ctx  = torch.matmul(attn, v)                                                            # (B,H,L,d)
        ctx  = ctx.transpose(1,2).contiguous().view(B, L, self.h*self.dk)                       # (B,L,D)
        return self.wo(ctx)

# ---- Decoder Block (Pre-LN) ----
class DecoderBlock(nn.Module):
    def __init__(self, d_model, n_heads, dropout=0.1):
        super().__init__()
        self.ln1  = nn.LayerNorm(d_model)
        self.attn = SelfAttention(d_model, n_heads, dropout=dropout)
        self.drop1 = nn.Dropout(dropout)

        self.ln2 = nn.LayerNorm(d_model)
        self.ffn = FeedForward(d_model, mult=4, dropout=dropout)
        self.drop2 = nn.Dropout(dropout)

    def forward(self, x, attn_mask=None):
        residual = x
        h = self.ln1(x)
        h = self.attn(h, attn_mask)
        h = self.drop1(h)
        x = residual + h

        residual = x
        h = self.ln2(x)
        h = self.ffn(h)
        h = self.drop2(h)
        x = residual + h

        return x
    
# ---- Decoder-only LM ----
class DecoderOnlyLM(nn.Module):
    def __init__(self, vocab_size, d_model=512, n_heads=8, n_layers=6, dropout=0.1, max_len=4096):
        super().__init__()
        self.tok = nn.Embedding(vocab_size, d_model)
        self.pos = PositionalEncoding(d_model, max_len=max_len)
        self.blocks = nn.ModuleList([DecoderBlock(d_model, n_heads, dropout) for _ in range(n_layers)])
        self.ln_f = nn.LayerNorm(d_model)
        self.lm_head = nn.Linear(d_model, vocab_size, bias=False)
        # weight tying
        self.lm_head.weight = self.tok.weight

    def forward(self, input_ids, attention_mask=None):  # input_ids: (B,L)
        x = self.tok(input_ids) * math.sqrt(self.tok.embedding_dim)
        x = self.pos(x)
        for blk in self.blocks:
            x = blk(x, attn_mask=attention_mask)
        x = self.ln_f(x)
        return self.lm_head(x)  # (B,L,V)

    @torch.no_grad()
    def generate(self, input_ids, max_new_tokens=50, eos_id=None, temperature=1.0, top_k=None):
        self.eval()
        for _ in range(max_new_tokens):
            attn_mask = (input_ids != 0).long()                # 0을 PAD로 가정(다르면 변경)
            logits = self.forward(input_ids[:, -1024:], attention_mask=attn_mask[:, -1024:])  # context crop 예시
            next_logits = logits[:, -1, :] / max(temperature, 1e-6)
            if top_k:
                v, ix = torch.topk(next_logits, top_k)
                mask = torch.full_like(next_logits, float('-inf'))
                next_logits = mask.scatter(1, ix, v)
            probs = F.softmax(next_logits, dim=-1)
            next_id = torch.multinomial(probs, num_samples=1)  # (B,1)
            input_ids = torch.cat([input_ids, next_id], dim=1)
            if eos_id is not None and (next_id == eos_id).all(): break
        return input_ids

import math, torch, torch.nn as nn
import torch.nn.functional as F
from torch.utils.data import DataLoader
from datasets import load_dataset
from transformers import AutoTokenizer

# ---- 설정 ----
block_size   = 128
batch_size   = 32
eval_bsz     = 64
epochs       = 3
lr           = 3e-4
weight_decay = 0.01
device       = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# ---- 토크나이저 (모델 vocab과 맞춰야 함) ----
tokenizer = AutoTokenizer.from_pretrained("gpt2")
if tokenizer.pad_token is None:
    tokenizer.pad_token = tokenizer.eos_token
pad_id = tokenizer.pad_token_id

# ---- 데이터셋 로드/토크나이즈/청크 ----
raw = load_dataset("wikitext", "wikitext-2-raw-v1")

def tokenize_fn(batch):
    return tokenizer(batch["text"], add_special_tokens=False)

def group_texts(examples):
    ids = sum(examples["input_ids"], [])
    n = (len(ids) // block_size) * block_size
    ids = ids[:n]
    input_ids = [ids[i:i+block_size] for i in range(0, n, block_size)]
    attention_mask = [[1]*block_size for _ in range(len(input_ids))]
    return {"input_ids": input_ids, "attention_mask": attention_mask}

tok = raw.map(tokenize_fn, batched=True, remove_columns=raw["train"].column_names)
chunks = tok.map(group_texts, batched=True)
chunks.set_format(type="torch", columns=["input_ids", "attention_mask"])

def collate_lm(batch):
    x_full = torch.stack([b["input_ids"] for b in batch], dim=0)   # (B, L)
    x = x_full[:, :-1]                                            # (B, L-1)
    y = x_full[:, 1:]                                             # (B, L-1)
    attn_mask = (x != pad_id).long()
    return x, y, attn_mask

train_loader = DataLoader(chunks["train"],      batch_size=batch_size, shuffle=True,  collate_fn=collate_lm)
valid_loader = DataLoader(chunks["validation"], batch_size=eval_bsz,   shuffle=False, collate_fn=collate_lm)

# ---- 모델/옵티마 (모델은 이미 있다고 가정) ----
# model 은 사용자 코드에서 정의되어 있다고 가정
d_model  = 512
n_heads  = 8
n_layers = 6
dropout  = 0.1

model = DecoderOnlyLM(
    vocab_size=tokenizer.vocab_size,
    d_model=d_model,
    n_heads=n_heads,
    n_layers=n_layers,
    dropout=dropout,
    max_len=block_size,   # block_size(=128)와 같거나 더 크게
).to(device)

optimizer = torch.optim.AdamW(model.parameters(), lr=lr, weight_decay=weight_decay)

model = model.to(device)  # <- 너의 Decoder-only 모델 인스턴스
optimizer = torch.optim.AdamW(model.parameters(), lr=lr, weight_decay=weight_decay)

# ---- 학습/평가 루프 ----
def run_epoch(loader, train=True):
    model.train(train)
    total_loss, total_tokens = 0.0, 0
    for x, y, attn_mask in loader:
        x = x.to(device)
        y = y.to(device)
        attn_mask = attn_mask.to(device)

        if train:
            optimizer.zero_grad()

        logits = model(x, attention_mask=attn_mask)          # (B, L, V)
        loss = F.cross_entropy(
            logits.reshape(-1, logits.size(-1)),
            y.reshape(-1),
            ignore_index=pad_id
        )

        if train:
            loss.backward()
            torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
            optimizer.step()

        total_loss   += loss.item() * y.numel()
        total_tokens += y.numel()

    return total_loss / max(total_tokens, 1)

for epoch in range(epochs):
    train_loss = run_epoch(train_loader, train=True)
    valid_loss = run_epoch(valid_loader, train=False)
    print(f"[epoch {epoch+1}] train loss {train_loss:.4f} | valid loss {valid_loss:.4f} | ppl {math.exp(valid_loss):.2f}")
```
