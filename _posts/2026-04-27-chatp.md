## Introduction

![image.png](/assets/img/2026-04-27-chatp/image.png)

- 이미지나 텍스트로부터 3D 인간 자세를 이해하고 추론하는 문제를 다룸.
- 기존 방법:
    - 이미지 기반: 자세는 추정하지만 의미 이해 부족
    - 텍스트 기반: 명시적 설명만 가능, 추론 불가
- LLM의 세계 지식과 추론 능력을 3D pose에 연결.
    - SMPL pose를 `<POSE>` 토큰으로 표현
    - LLM 출력 → pose parameter로 변환
- 기존 정확도는 낮지만 proof-of-concept로 의미 있음.
- LLM이 pose를 이해하면:
    - 추가 학습 없이
    - 세계 지식 기반 pose 추론 가능

### SPG

- 암시적 질문 → pose 생성 (예: 피곤하면 자세가 어떻게 변하는가

### RPE

- 전체 이미지 기반 특정 사람 pose 추론 (예: 안경 쓴 사람들의 자세)

### Contribution

1. pose 생성 가능한 멀티모달 LLM (ChatPose)
2. SPG, RPE 문제 정의
3. 기존 LLM 대비 성능 향상

## Method

![image.png](/assets/img/2026-04-27-chatp/image%201.png)

### Architecture

- ChatPose는 다음으로 구성됨:
    - 멀티모달 LLM (f_ϕ)
    - SMPL projection layer (g_Θ)
    - SMPL 모델
- 입력: 텍스트 X_q, 이미지 X_v (선택)
- 출력: 텍스트 응답 Y_t
- 동작:
    - LLM이 "<POSE>" 토큰을 생성
    - 해당 토큰의 embedding H_pose 추출
    - g_Θ를 통해 SMPL pose 파라미터 θ 생성
    - SMPL 모델 M(θ, β)로 3D mesh 생성 (β는 평균값 사용)

### Training

- 학습 대상:
    - SMPL projection layer (g_Θ)
    - LLM (LoRA 적용)
- 고정:
    - vision encoder
    - vision projection layer
- Loss:
    - 텍스트 생성 loss (cross entropy)
    - pose loss (L1 distance)
    - 총 loss: L = λ_t * CE + λ_θ * |θ̂ - θ|
- 데이터 구성:
    - Text → Pose
    - Image → Pose
    - Multimodal instruction 데이터

### Reasoning about Human Pose

- 학습 후 모델은:
    - 이미지 기반 pose estimation
    - 텍스트 기반 pose 생성
    - 대화 기반 추론
- 새로운 task:
    - SPG (Speculative Pose Generation)
        - 암시적 질문 → pose 생성
    - RPE (Reasoning-based Pose Estimation)
        - 전체 장면 기반 특정 사람 pose 추론

## Experiments

- 저자들은 멀티모달 LLM 백본으로 LLaVA-1.5V-13B을 사용
- 비전 인코딩에는 CLIP
- LLM 백본으로는 대화 데이터로 Llama 2를 파인튜닝한 Vicuna-13B 를 사용
- CLIP 인코더와 vision projection 레이어는 freeze한 상태로 유지하며, SMPL 프로젝션 레이어는 처음부터 학습하고, LLM은 LoRA를 이용해 fine-tunning
- SMPL 프로젝션 레이어는 MLP로 구성된다.
- 이전 연구들을 따라, 우리의 네트워크는 SMPL 자세를 6D Rotation으로 예측하며, 이는 손실 계산을 위해 회전 행렬로 변환된다.

### Datasets

- Text to Pose Generation: PoseScript의 text-to-SMPL pose 쌍을 사용한다.
- Human Pose Estimation: Human3.6M, MPI-INF-3DHP, COCO, MPII

## Conclusion

- ChatPose는 3D 인간 자세 추정과 LLM의 일반적인 추론 능력을 통합하기 위한 첫걸음을 제시한다.
이 연구를 통해 몇 가지 중요한 점을 확인할 수 있다.
- 첫째, 멀티모달 LLM은 이미지로부터 3D 인간 자세를 추론하도록 파인튜닝될 수 있다. 특히, 인체 각 부위의 연속적인(real-valued) 회전을 추론할 수 있다. 우리가 아는 한, 이러한 모델이 이 작업을 직접적으로 수행할 수 있음을 보여준 최초의 사례이다.
- 둘째, 이 모델은 3D 인간 자세와 언어를 연결할 수 있다. 이는 응용 측면과 학습 측면 모두에서 다양한 가능성을 열어준다는 점에서 중요하다.
- 셋째, 우리는 사용자가 텍스트와 이미지를 이용하여 언어 모델과 3D 인간 자세에 대해 대화할 수 있는 새로운 활용 방식을 제시하였다.
이 연구는 LLM을 활용해 3D 인간 자세를 추론하고 활용하는 새로운 방향의 시작점이 될 것이라고 본다.
- 이미지 기반 3D 자세 추정의 정확도는 최신의 특화된 회귀 모델보다 낮다.
또한, 언어와 자세를 연결하는 더 높은 품질의 데이터가 필요하다. 최근 LLM 연구에서 중요한 교훈 중 하나는 데이터의 규모와 품질이 핵심이라는 점이다.
- 추가적으로, 비전 인코더를 고정(freeze)한 것도 하나의 한계이며, 이는 더 강력한 백본을 사용하거나 전체 모델을 더 많은 데이터로 파인튜닝함으로써 개선될 수 있다.
- 향후 연구에서는 ChatPose가 3D 자세에 대해 다중 턴 대화를 더 잘 수행하도록 개선할 필요가 있다.
또한 자세 편집(pose editing) 기능을 추가하는 것도 가능하다.
- 더 나아가, 3D 신체 형태(body shape)나 인간 동작(motion)을 추론하는 방향으로 확장하는 것도 비교적 수월할 것으로 보인다.
- 특히 최근 비디오 모델의 발전을 고려할 때, 비디오 입력으로 확장하는 것은 매우 유망한 방향이다.
