## Introduction

- 최근 Vision Transformer(ViT)는 이미지 분류, 객체 검출, 세그멘테이션 등 다양한 단일 모달(single-modal) 비전 작업에서 높은 성능을 보였다.
- 그러나 실제 비전 문제에서는 RGB 이미지, depth, point cloud 등 여러 모달리티(modality)를 동시에 활용하는 경우가 많다.
- 멀티모달 데이터를 Transformer에 적용하는 것은 직관적으로 성능 향상을 기대할 수 있지만, 단순히 토큰을 결합(concatenation)하는 방식은 모달 간 정렬 정보(alignment)를 충분히 활용하지 못한다.
- 이러한 방식은 서로 다른 모달리티 간의 attention이 희석되어 성능이 오히려 저하될 수 있다.
- 이 논문은 이러한 문제를 해결하기 위해 TokenFusion이라는 멀티모달 토큰 융합 방법을 제안한다.
- TokenFusion은 각 모달리티 Transformer에서 정보량이 적은 토큰을 동적으로 탐지하고, 해당 토큰을 다른 모달리티에서 투영된 특징으로 대체하여 멀티모달 상호작용을 수행한다
- 이를 통해 기존 single-modal Transformer 구조를 크게 변경하지 않으면서도 모달 간 상호작용을 효과적으로 학습할 수 있다.

## Method

### Basic Transformer Formulation

- 입력 데이터가 M개의 모달리티로 구성된다고 가정하면 $x = \{x_1, x_2, ..., x_M\}$ 각 모달리티는 N개의 토큰과 C개의 채널을 가진다.
- Transformer의 $i$ 번째 레이어에서 모달리티 $m$의 feature는 다음과 같이 계산된다.
    - $\hat e_{m}^l = \text{MSA}(\text{LN}(e^l_m))$
    - $e^{l+1}_m = \text{MLP}(\text{LN}(\hat e ^l_m))$
    - MSA: Multi-head Self Attention
    - MLP: Feed Forward Network
    - LN: Layer Normalization
- 각 모달리티는 독립적인 Transformer를 통해 feature를 계산한다.

### Multimodal Fusion Problem

- 멀티모달 Transformer에서 중요한 문제는 어디에서 어떻게 모달 간 feature interaction을 수행할 것인가이다.
- 기존 접근은 두 가지로 나눌 수 있다.
    1. Alignment-agnostic fusion
        - 단순 토큰 concat
        - 모달 간 정렬 정보를 활용하지 못함
    2. Alignment-aware fusion
        - 픽셀 위치나 좌표를 이용해 모달 간 대응 관계를 이용
        - 구조 설계가 복잡하고 모델 변경이 큼

### Token Importance Estimation

- TokenFusion의 핵심 아이디어는 중요하지 않은 토큰을 다른 모달리티의 정보로 대체하는 것이다.
- 각 레이어에서 토큰 중요도를 예측하기 위해 scoring function을 정의한다.

$$
s^l(e^l) = \text{MLP}(e^l) \in [0, 1]^N
$$

- 이를 통해 토큰 중요도를 계산한다.
- MSA 출력은 다음과 같이 수정된다.

$$
\hat e^l_m = \text{MSA}(\text{LN}(e^l_m)\cdot s^l(e^l_m))
$$

- 또한 토큰 pruning을 유도하기 위해 다음 loss를 추가한다.
    
    $$
    L = \sum_{m=1}^{M} \left( L_m + \lambda \sum_{l=1}^{L} \| s_l(e_l^m) \|_1 \right)
    $$
    
    - Lₘ : task loss
    - λ : sparsity 가중치

### Multimodal Token Fusion

중요도가 낮은 토큰은 다른 모달리티에서 투영된 feature로 대체된다.

$$
e_l^m =
e_l^m \odot \mathbf{1}_{s_l(e_l^m) \ge \theta}
+
\mathrm{Proj}_M^{m'}(e_l^m) \odot \mathbf{1}_{s_l(e_l^m) < \theta}
$$

- 중요 토큰 → 그대로 유지
- 중요하지 않은 토큰 → 다른 모달리티 feature로 교체.
    - $\mathrm{Proj}_M^{m'}(e_l^m)$ : 다른 modality $m'$ projection 된 token
- 이 과정은 각 Transformer layer 전에 수행된다.
    - 중요한 single-modal token 구조 유지
    - 필요한 부분만 cross-modal interaction 수행

### Residual Positional Alignment (RPA)

- 토큰을 다른 모달리티 feature로 대체하면 위치 정보가 사라질 수 있다.
- 이를 해결하기 위해 Residual Positional Alignment (RPA)를 도입한다.
- 핵심 아이디어
    - 토큰이 다른 모달리티 feature로 대체되더라도
    - 원래 위치의 positional embedding을 유지

→projected feature + original positional embedding 형태로 사용하여 모달 간 위치 정렬을 유지한다.

### Homogeneous Modalities (ex: RGB + Depth와 같이 동일한 공간 정렬)

- Transformer weights 공유
- LayerNorm만 modality별로 분리
- token projection은 identity 사용
- 동일 위치 토큰끼리 교체

→ RGB token (i) ↔ Depth token (i)

### Heterogeneous Modalities (ex: 이미지 + point cloud 구조)

- 서로 다른 Transformer 사용
- projection을 위한 MLP 사용
- 3D point → 2D image patch projection 수행
- 3D point (x,y,z)는 카메라 행렬을 이용해 2D 이미지 좌표로 변환된다.
    - [u, v, z]ᵀ = K · Rₜ · [x, y, z, 1]ᵀ
- 이를 통해 대응되는 image patch token을 찾고 해당 feature로 token을 대체한다.

## Conclusion

- 이 논문은 Vision Transformer 기반 멀티모달 학습을 위해 TokenFusion을 제안한다.
- TokenFusion은 중요하지 않은 토큰을 다른 모달리티의 특징으로 대체하여 멀티모달 상호작용을 효율적으로 수행한다.
- 주요 특징은 다음과 같다.
    - 기존 single-modal Transformer 구조 유지
    - 중요 토큰을 보존하면서 multimodal interaction 수행
    - Residual positional alsignment로 모달 정렬 유지
    - homogeneous 및 heterogeneous modality 모두 적용 가능
- 이를 통해 다양한 멀티모달 비전 작업에서 기존 방법보다 높은 성능을 달성하였다.
