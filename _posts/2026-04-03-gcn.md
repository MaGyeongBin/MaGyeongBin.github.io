## Introduction

- 저자들은 그래프에서 노드를 분류하는 문제를 고려한다. 이때, label은 전체 노드중 일부에 대해서만 주어진다. 이 문제는 graph-based semi-supervised learning으로 볼 수 있으며, 여기서 label 정보는 어떤 형태의 explicit graph-based regularization을 통해 그래프 전반으로 퍼지게 된다.
- 예를 들어, loss funcition에 graph Laplacian regularization term을 추가할 수 있다.
    
    $$
    \mathcal{L} = \mathcal{L}_0 + \lambda \mathcal{L}_{\text{reg}} \text{, with } \mathcal{L}_{\text{reg}} = \sum_{i,j} A_{ij} \left\Vert f(X_i) - f(X_j) \right\Vert^2 = f(\mathbf{X})^\text{T} \Delta f(\mathbf{X})
    $$
    
    - $L_0$ = label이 존재하는 노드들에 대한 supervised loss를 의미하고
    - $f(\cdot)$ =  neural network와 같은 differentiable funciton
    - $\lambda$ = weight factor,
    - $X$ = 노드 feature vector $X_i$ 들로 이루어진 행렬.
    - $\Delta = D-A$ 는 unnormalized graph Laplacian을 의미하며, 이는 undirected graph $G = (V,E)$ 에 대해 정의된다.
    - $V$ = 노드 집합
    - $E$ = edge 집합
    - $A \in \mathbb{R}^{N\times N}$ 는 adjacency matrix, $D_{ii} = \sum_j A_{ij}$ 는 degreee matrix.
- 여기서 서로 연결된 노드들은 동일한 label을 가질 가능성이 높다는 가정에 기반.← 연결된 노드들은 비슷한 output을 내도록 강제.
- 하지만 이 가정은 modeling capacity를 제한 할 수 있다. 왜냐하면 graph의 edge가 항상 노드 간의 similarity를 의미하는것은 아니고, 추가적인 정보를 담을 수 있기 때문.
- 본 연구에서는 graph structure를 neural network 모델 $f(X, A)$ 에 직접 반영하고, label이 있는 노드들에 대해 supervised target $L_0$ 만을 사용하여 학습을 진행. loss function에서 explicit graph-based regularization을 사용하는것을 피한다.
- 본 논문의 main contribution은
    - 그래프에서 직접 동작하는 neural network 모델을 위한 단순하면서도 안정적인 layer-wise propagation rule을 제안하고, 이것이 spectral graph convolution의 first-order approxiamtion으로부터 어떻게 유도될 수 있는지를 보인다.
    - 둘째, 이러한 graph-based neural network 모델이 그래프에서의 semi-supervised node calssification을 빠르고 확장 가능하게 수행할 수 있음을 보인다.

## FAST APPROXIMATE CONVLUTIONS ON GRAPHS

- 논문 전반에서 사용할 특정 graph-based neural network model $f(X, A)$ 에 대한 theoretical motivation을 제시. 우리는 다음과 같은 layer-wise propagation rule을 갖는 multi-layer Graph Convolutional Network(GCN)을 고려.
    
    $$
    H^{(l+1)} = \sigma \left(\tilde{D}^{-\frac{1}{2}} \tilde{A} \tilde{D}^{-\frac{1}{2}} H^{(l)} W^{(l)}\right)
    $$
    
    - $\tilde A = A + I_N$ 는 undirected graph $G$ 의 adjacency matrix에 self-connections을 추가한 것.
    - $I_N$ 은 identity matrix이며, $\tilde D_{ii} = \sum_j \tilde A_{ij}$ 는 degree matrix를 의미. 또한 $W^{(l)}$ layer-specific trainable weight matrix이다.
        - 즉 1) 자기 자신 포함, 2)이웃 노드 개수를 나눠서 normalization 을 하여, scale 안정적
    - $\sigma$ 는 activation funciton
- $H^{(l)} \in \mathbb{R}^{N\times D}$ 는 $l$ 번째 layer에서의 activation matrix를 의미하며, 초기값은 $H^{(0)} = X$ 이다.
- 이후에서는 이러한 propagation rule의 형태가 그래프상의 localizaed spectral filters에 대한 first-order approximation을 통해 어떻게 도출될 수 있는지를 보인다.

### SPECTRAL GRAPH CONVOLUTIONS

- 저자들은 그래프에서의 spectral convolutions를 다음과 같이 정의한다. 이는 신호 $x \in \mathbb{R}^N$ (각 노드마다 하나의 scalar 값)을 Fourier domain에서, 파라미터 $\theta \in \mathbb R^N$ 로 parameterized된 필터 $g_\theta = \text{diag}(\theta)$ 와 곱한는 것으로 정의.

$$
g_\theta *x = Ug_\theta U^T x
$$

- 여기서 U는 normalized graph Laplacian 의 eigenvector들로 이루어진 행렬,
    
    $$
    L = I_N - D^{-1/2}AD^{-1/2} = U\Lambda U^T
    $$
    
    - $\Lambda$ 는 eigenvalue 들로 구성된 diagonal matrix.
    - $U^Tx$ 는 신호 $x$ 의 graph Fourier Transform을 의미.
    - $g_\theta$ 를 $L$ 의 eigenvalue 들에 대한 함수, 즉 $g_\theta(\Lambda)$ 로 이해.
- eigenvector들로 이루어져있는 함수를 직접 계산하는것은 비용이 O(N^2)의 복잡도를 가지고 있기 때문에 U를 구하는것 자체는 매우 비싼 연산이 된다.
- 이 문제를 해결하기 위해, $g_\theta(\Lambda)$ 를 Chebyshev polynomial $T_k(x)$ 의 k차까지 truncated expansion으로 근사할 수 있다고 제안.
    
    $$
    g_{\theta'}(\Lambda) \approx \sum_{k=0}^{K} \theta'_k \, T_k(\tilde{\Lambda})
    $$
    
    - 여기서 rescaled 된 $\tilde{\Lambda} = \frac{2}{\lambda_{\max}} \Lambda - I_N$
- Chebyshev polynomial은 다음과 같은 recursive 정의를 갖는다.

$$
T_k(x) = 2xT_{k-1}(x) - T_{k-2}(x)
$$

$$
T_0(x) = 1, T_1(x) = x
$$

- 다시 convolution 정의로 돌아가게 되면 다음과 같이 근사된다.
    
    $$
    g_{\theta'} * x \approx \sum_{k=0}^{K} \theta'_k T_k (\tilde{L})x
    $$
    
    - 여기서 $\tilde L = \frac{2}{\lambda_{max}}L - I_N$
    - $T_k(\tilde L) = UT_k(\tilde \Lambda) U^T$ ← $L = U\Lambda U^T$
- 이 표현은 $L$ 에 대한 K차 polynomial이므로 K-localized 특성을 가진다. 즉, 노드로부터 최대 K-step 떨어진 노드들까지만 영향을 받는다.
- 이렇게 근사된 계산 복잡도는 O(|E|), 즉 edge 수에 선형적이다.

### LAYER-WISE LINEAR MODEL

- graph convolution에 기반한 neural network 모델은 convolutional layer를 여러개 쌓고, 각 layer 뒤에 point-wise non-linearity를 적용하는 방식으로 구성할 수 있다.
- 이제 layer-wise convolution 연산을 $K=1$ 로 제한한다고 가정하면, 이는 $L$ 에 대해 linear한 함수이며, 따라서 graph Laplacian spectrum 상에서도 linear funciton이 된다.
- 이러한 방식으로 여러 layer를 쌓으면 여전히 다양한 convolutional filter function을 표현할 수 있다. 동시에 Chebshev polynomial과 같은 explict parameterization에 제한되지 않는다.
- 이러한 모델은 social network, citation network, knowledge graph등과 같이 node degree distribution이 매우 넓은 그래프에서 local neighborhood 구조에 대한 overfitting 문제를 완화할 수 있을 것으로 기대된다.
- 또한, 동일한 computional budget 하에서 이 layer-wise linear formulation은 더 깊은 모델을 구성할 수 있게 해주며, 이는 다양한 도메인에서 modeling capacity를 향상시키는 것으로 알려져있다.
- 이 linear formulation의 GCN에서는 추가로 $\lambda_{max} \approx 2$ 로 근사. 이는 neural network parameter가 학습 과정에서는 이러한 scale 변화에 적응할 수 있다고 기대.
- 이러한 근사를 적용하게 되면, $g_{\theta'} *x\approx \theta'_0 x + \theta'_1 (L-I_N)x = \theta'_0x-\theta'_1D^{-1/2}AD^{-1/2}x$
- 여기서 두개의 free parameter $\theta_0',\theta_1'$ 가 존재. 이 filter parameter는 그래프 전체에 공유될 수 있다.
- 이러한 형태의 filter를 여러번 연속 적용하면, 결과적으로 k개의 convolutional layer를 쌓은 것과 같으며, 이는 k-th order neightborhood에 대한 convolution 과 동일한 효과를 가진다.
- 실제 구현에선는 overfitting을 방지하고 layer당 연산량을 줄이기 위해 paraemeter 수를 더 줄이는것이 유리.

$$
g_{\theta} \star x \approx \theta \left( I_N + D^{-\frac{1}{2}} A D^{-\frac{1}{2}} \right) x
$$

- 여기서 단일 parameter $\theta = \theta'_0  = -\theta'_1$ 를 사용.
    - 그러나  주의할점은 $I_N + D^{-1/2}AD^{-1/2}$ 의 eigenvalue의 범위가 [0, 2]라는 것. 이 operator를 반복적으로 적용하면 deep neural network에서 gradient exploding + vanishing 문제가 발생 가능.
    - 이 문제를 해결하기 위해 renormalization trick을 도입.
        
        $$
        I_N + D^{-1/2}AD^{-1/2} \rightarrow \tilde D ^{-1/2}\tilde A \tilde D^{-1/2}
        $$
        
        - $\tilde A = A + I_N$
        - $\tilde D_{ii} = \sum_j\tilde A_{ij}$
- 이 정의는 $X \in \mathbb R^{N\times C}$(N: node 수, C: channel 수)로 일반화 할 수 있으며, F 개의 filter 또는 feature map을 적용하면 다음과 같다.
    
    $$
    Z = \tilde D^{-1/2}\tilde A \tilde D^{-1/2} X \Theta
    $$
    
    - $\Theta \in \mathbb R^{C \times F}$ : filter parameter matrix
    - $Z \in \mathbb R^{N\times F}$: convolution 결과
- 이 filtering 연산의 복잡도는 $O(|E|FC)$ 이며, 이는 $\tilde AX$ 를 sparse matrix의 dense matrix의 곱으로 효율적으로 계산할 수 있기 때문이다.

### Example

- symmetric adjacency matrix A를 가지는 rmfovmdptj semi-supervised node classification을 위한 two-layer GCN을 고려한다.
- 먼저, pre-processing 단계에서 다음을 계산한다.
    
    $$
    \hat A = \tilde D^{-1/2} \tilde A \tilde D ^{-1/2}
    $$
    
- 이후, forward model은 다음과 같은 형태를 갖는다.
    
    $$
    Z = f(X, A) = \text{softmax}(\hat A \text{ReLU}(\hat A XW^{(0)})W^{(1)})
    $$
    
    - $W^{(0)} \in R ^{C\times H}$ : input-to-hidden weight matrix
    - $W^{(1)}\in \mathbb R ^{H\times F}$: hidden-to-output weight matrix
    - softmax는 row-wise로 적용.
- semi-supervised multi-class classification에서는, labeled example들에 대해 cross-entropy error를 다음과 같이 계산한다
    
    $$
    L = -\sum_{l\in Y_L}\sum_{f=1} Y_{lf}\text{ln}Z_{lf}
    $$
    
    - 여기서 $Y_L$ 은 label이 존재하는 node index들의 집합.
- neural network의 weight $W^{(0)}, W^{(1)}$ 는 gradient descent를 사용하여 학습.
- 이 논문에서는 매 training iteration마다 전체 dataset을 사용하는 batch gradient descent를 수행.

## DISCUSSION

### SEMI-SUPERVISED MODEL

- 본 실험에서 semi-supervised node classification을 위한 저자들의 방법들은 최근의 관련 방법들보다 상당한 성능 향상을 보였다.
- graph-Laplacian regularization 기반 방법들은 edge가 단순히 node 간 simillarity로 가정하는 한계로 인해 성능이 제한될 가능성이 높다.
- 반면, skip-gram 기반 방법들은 multi-step pipeline에 의존하기 떄문에 최적화가 어렵다는 한계가 있다.
- 따라서 저자들의 제안 모델은 이러한 두 가지 한계를 모두 극복하면서도, 관련 방법드록 비교했을 때 wall-clock time 기준의 효율성 측면에서도 우수한 성능을 보인다.
- 각 layer에서 이웃 node로부터 feature 정보를 전파하는 방식은 label 정보만을 aggregation하는 방법들 보다 classificiation 성능을 향상.
- 또한 우리는 제안된 renormalized propagation model 다음과 같은 장점을 가진다는것을 보인다.
    1. 더 높은 효율성
    2. 더 높은 예측 성능
