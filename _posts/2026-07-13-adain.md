# Arbitrary Style Transfer in Real-time with Adaptive Instance Normalization

## 1. Introduction

이전 연구를 통해서 선구적인 연구는 심층 신경망 DNN이 이미지의 콘텐츠 정보뿐만 아니라 style 정보도 인코딩한다는 것을 보여주었다. 또한 이미지의 스타일과 콘텐츠는 어느 정도 분리 가능하며, 이미지의 콘텐츠를 유지한 채 스타일만 변경하는 것이 가능하다. 그러나 최적화 과정에 의존하기 때문에 처리 속도가 매우 느리다는 문제가 있다.

본 연구는 유연성과 속도 사이의 근본적인 딜레마를 해결하는 최초의 신경망 기반 스타일 전이 알고리즘을 제안. 제안하는 방법은 임의의 새로운 스타일을 실시간으로 전이할 수 있다. 즉, 최적화 기반 프레임워크가 가지는 유연성과 가장 빠른 FFN 방식에 가까운 속도를 동시에 제공.

본 방법은 FFN 스타일 전이에서 놀라울 정도로 효과적인 Instance Normalization 계층에서 영감을 얻음. 이와 같은 방법이 효과적인 이유를 설명하기 위해, 본 연구에서는 새로운 해석을 제안. 즉, Instance Normailization은 이미지의 스타일 정보를 포함하는 것으로 알려진 feature statics를 정규화함으로써 스타일 정규화를 수행.

이러한 해석을 바탕으로, 본 연구에서는 IN을 간단하게 확장한 Adaptive Instance Normalization을 제안. AdaIN은 content input 과 style input 이 주어졌을 때, 콘텐츠 입력의 평균과 분산을 스타일 입력의 평균과 분산에 맞도록 조정. 실험을 통해 AdaIN 이 특징 통계를 전달함으로써, 콘텐츠 입력의 콘텐츠와 스타일 입력의 스타일을 효과적으로 결합하는것을 확인.

## 2. Related Work

**Style transfer**

초기 스타일은 low-level statistics만 사용해서 semantic structure를 잘 표현하지 못했다. 그러나 Gatys et al., CVPR 2016은 CNN feature statistics를 이용하면서 neural style transfer의 중요한 전환점을 만들었음.

## 3. Background

### 3.1 Batch Normalization

Ioffe와 Szegedy의 선구적인 연구는 feature statics를 normalization 함으로써 feed-forward network 의 학습을 크게 용이하게 하는 Batch Normalization layer를 제안.

원래 용도는 discriminative network의 학습을 가속하기 위해 설계, generative image modeling에서도 효과적인 것으로 확인. 

입력 $x \in \mathbb R^{N\times C\times H \times W}$가 주어졌을 때, BN은 각 feature channel에 대해 mean과 standard deviation을 normallization한다.

$$
BN(x) = \gamma(\frac{x-\mu(x)}{\sigma(x)}) +\beta
$$

여기서 $\gamma, \beta \in \mathbb R^C$ 는 data로부터 학습되는 affine parameter. 각 feature channel 별로 batch size와 spatial dimenstion 전체에 걸쳐 계산.

### 3.2 Instance Normalization

기존의 feed-forward stylization method에서는 style transfer network의 각 convolutional layer 뒤에 BN layer가 포함되었다. 그러나 Ulyanov et al.은  BN layer를 단순히 IN layer로 교체하는 것만으로도 성능이 크게 향상될 수 있음을 발견.

$$
BN(x) = \gamma(\frac{x-\mu(x)}{\sigma(x)}) +\beta
$$

BN layer와 다르게 여기서의 $\mu(x), \sigma(x)$ 는 각 sample 과 각 channel에 대해 독립적으로 spatial dimension  전체에서 계산된다.

### 3.3 Conditional Instance Normalization

하나의 affine parameter 집합 $\gamma$ 와 $\beta$ 를 학습하는 대신, Dumoulin et al. 은 각 style $s$ 에 대해 서로 다른 parameter $\gamma^s$ 와 $\beta^s$ 를 학습하는 Conditional Instance Normalizaion (CIN) layer를 제안. 

$$
CIN(x; s) = \gamma^{s}\left(\frac{x - \mu(x)}{\sigma(x)}\right) + \beta^{s}
$$

training 과정에서는 고정된 style 집합 $s \in \{1, 2, ..., S\}$ 중에서 하나의 style image와 해당 index $s$ 를 무작위로 선택. 이들의 experiment 에서는 $S=32$ 개의 style을 사용.

이후 content image는 style transfer network를 통과하며, CIN layer에서는 선택된 style $s$ 에 해당하는 $\gamma^s$  와 $\beta^s$ 가 사용. 흥미롭게도 network는 동일한  convolutional parameter를 사용하면서도, IN layer의 affine parameter만 다르게 적용함으로써 완전히 서로 다른 style 이미지를 생성 가능.

그러나 이 방법은 새로운 arbitrary new style에 adapt할 수 없다.

## 4. Interpreting Insance Normalization

![image.png](/assets/img/2026-07-13-adain/image.png)

CIN 에서 큰 성공을 거두었음에도 불구하고, 왜 이 방법들이 특히 style transfer에서 효과적인지는 여전히 명확하지 않다.

Ulyanov et al. 은 IN의 성공 원인을 content image의 contrast에 대한 invariance 때문이라고 설명하였다. 그러나 IN은 pixel space가 아닌 feature space에서 수행되므로, 단순한 pixel space의 contrast normalization 보다 더 근본적인 영향을 가질 가능성이 있다. 더욱 놀라운 점은 IN의 affine parameter 가 output image의 style을 완전히 변화시킬 수 있다는 사실.

DNN의 convolutional feature statistics가 image style을 포착할 수 있다는 것은 기존 연구를 통해 알려져 있다. Gatys et al.은 second-order statistics를 optimization objective로 사용. 반면 최근 연구는 channel-wise mean과 variance를 포함한 다양한 statistics를 matching 하는 것 역시 style transfer에 효과적이라는 것을 보여주었다.

이러한 observation을 바탕으로, 우리는 Instance Normalization 이 feature statistics, 즉 mean과 variance를 normalization 함으로써 original style infromation을 제거하는 일종의 style normalization 을 수행한다고 주장.

이를 확인하기 위해 improved texture networks의 코드를 사용하여 IN layer 또는 BN layer를 적용한 single-style transfer를 수행. 예상한 대로 IN을 사용한 model은  BN model보다 빠르게 style loss에 대해서 converge하였다. → 이를 통해서 1) contrast를 잘 지워서? 2) 혹은 style을 잘 지운다는 두 가지의 가설이 나올 수 있음.

따라서 Figure1-(b)를 통해 입증. 이는 contrast 차이를 제거한 이미지를 사용. 그러나 여전히 IN이 BN보다 훨씬 좋은 성능을 기록함. 따라서 IN의 효과를 단순 contrast normalization으로 설명할 수 없음.

이번에는 style을 잘 지운다는 가설을 검증하기 위해 style transfer 모델을 이용해 모든 이미지의 스타일을 통일함. 그 결과 BN과 IN의 차이가 크게 줄음. 따라서 IN은 contrast 뿐만 아니라 style normalization을 수행함.

## 5. Adaptive Instance Normalization

따라서 IN은 각 sample feature mean과 variance를 normalizae 해서 original style 정보를 제거하는 역할을 한다. IN이 affine parameter $\gamma, \beta$ 에 의해 하나의 style로 normalize한다면, 이 값을 style image에 맞게 매번 바꾸면 arbitrary style도 넣을 수 있지 않을까 하는 아이디어에서 시작한다. 따라서 이어지는 수식은 아래와 같다.

$$
AdaIN(x, y) = \sigma(y)(\frac{x-\mu(x)}{\sigma(x)})+\mu(y)
$$

## 6. Experimental Setup

![image.png](/assets/img/2026-07-13-adain/image%201.png)

### 6.1 Architecture

제안하는 style transfer network $T$ 는 content image $c$ 와 arbiatrary style image $s$ 를 입력으로 받고, content image의 content와 style image의 style을 결합한 output image를 생성.

즉, VGG에서 content와 style feature 를 뽑고, AdaIN에서 statistics를 맞춘 뒤, decoder가 다시 image로 복원.

### 6.2 Training

Content 이미지는 MS-COCO를 사용하고, style image로는 주로 WikiArt에서 수집된 painting dataset을 사용하여 network를 학습.

decoder가 AdaIN target feature 를 제대로 복원하도록 content loss를 주고, 생성된 image의 channel-wise mean과 standard deviation이 style image와 같아지도록 style loss를 준다.
