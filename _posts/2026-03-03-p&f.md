## Introduction

- Semantic segmentation은 이미지의 각 pixel데 대해 class를 할당하는 pixel-wise calssification을 의미.
- 잘 알려져 있듯이, 기존 Convolutional Neural Networks는 전통적인 방법들에 비해 local texture features를 효과적으로 추출하는데 뛰어난 성능, 그러나 한쪽 코너의 patch가 다른 모서리의 patch와 관련될 수 있다는점을 고려하여, long-range depedencies를 위해 CNN은 더 큰 receptive field.
- 다양한 convolutional architectures 설계, multiple kernels를 concatenate하여 더 큰 receptive field, attention based mehtods:attention score 도입, fusion-based(서로 다른 stage에서 feature를 융합하여 multi-scale semantics를 집계)와 같은 기존의 연구 → Transformers based mehtods 최근 연구 방향.
- 그러나 이러한 방법들 대부분은 많은 parameters를 수반, 추가 연구 필요
- Indoor semantic segmentation은 복잡한 layout과 다양한 occlusion으로 인해 가장 도전적인 문제.
- 최근 depth sensor의 보급으로 RGB-D images와 함께 depth map을 쉽게 획득할 수 있게 되었으며, 이는 multi-modal fusion 관련 연구를 더욱 촉진. RGB와 depth데이터를 fusion하는 방식은 fusion 발생하는 시점에 따라 세 가지 대표적인 pipeline으로 구분된다.
    - Early Fusion: feature extraction 이전 단계에서 두 modality를 concat
    - Middle Fusion: feature level fusion 은 feature learnning 과정 중 서로 다른 modality의 feature를 aggregation하는 방식
    - Late Fusion: feature extraction 이후 단계에서 fusion
- 아래의 이미지 (a)는 기존 연구들의 pipeline이다.
    
    ![image.png](/assets/img/2026-03-03-p&f/image%201.png)
    
    - 그러나 실제 구현 과정에서 assignment가 효과적이지 않으며, graph construction 과정에서 positional properties가 완전히 무시 되고 있음.
- 본 논문의 주요한 contribution
    - RGB-D semantic segmentation에서 발생하는 irregular patch 오류를 효과적으로 해결하기 위해 기존 pixel-node-pixel pipeline에 3D branch를 추가하고, 두 modality의 feature를 texture-prior style로 fusion하는 방법을 제안.
    - Graph construction 과정에서 발생하는 Biased-Assignment 및 ambiguous-locality 문제를 완화하기 위해, projection matrix에 constraint를 추가하고 adjacent matrix 생성 방식을 변경.
    - NYU-v2 및 SUN RGB-D dataset에서의 extensive experiments를 통해 제안한 방법이 경쟁력 있는 state-of-the-art 성능

## The proposed method

### Overview

![image.png](/assets/img/2026-03-03-p&f/25d35251-c079-4625-8d51-336c7afa1909.png)

- CNN으로 depth map을 더 잘 처리하기 위해, 우리는 one-channel detph map을 normal map으로 변환.
- 두 모듈을 효율적이고, 효과적으로 fusion하기 위해 texture-oriented projection matrix와 summation operation을 사용하여 seamless feature fusion을 수행.
- Biased-Assignment 문제를 완화하기 위해, projection matrix 제약을 추가. 이를 위해 KL-loss를 제안하여 graph의 assignment score가 균일하게 분포되도록 강제.
- graph에 positional information을 embedding 하기 위해, graph construction 단계에서 Euclidean distance를 기반으로 adjacency matrix를 생성.

### Data Pre-Processing

![image.png](/assets/img/2026-03-03-p&f/image%201.png)

- RGB + Depth 데이터를 입력으로 받아, encoder-decoder 기반 segmentation 네트워크인 DeepLabV3+를 채택하여 preliminary feature map을 추출.
- 3D branch의 경우, RGB 와 depth 데이터 간의 본질적인 차이로 인해 RGB데이터에 널리 사용되는 convolution operator가 depth map 처리에 최적이 아닐 수 있음.
- 네트워크가 이러한 feature를 더 잘 처리하고 후속 fusion operation을 수행할 수 있도록 하기 위해, depth를 normal map으로 인코딩 하여 3D branch의 입력으로 사용.
- 두 modality의 복잡도 차이를 고려하여, 3D branch의 backbone은 상대적으로 간단하게 설계.(2D branch: ResNet50, 3D branch: ResNet18) ← 최종 성능에 손해를 주지 않는다는것을 확인.
- 이전 연구에서 camera parameters와 depth 데이터를 이용하면 depth map을 point cloud 집합으로 projection 가능, 이를 기반으로 normal vector를 계산 가능.
- **Pinhole Camera model**
    
    $$
    \begin{align*}x_i &= (u_i - c_x) \ast z_i / f_x \\y_i &= (v_i - c_y) \ast z_i / f_y\end{align*}
    $$
    
- **Neighborhood Defining**
    - pixel i의 normal vector를 구하기 위해서 tangent plane을 결정이 필요하다.
    - 이 tangent plane은 x, y, z 방향으로 결정, 구체적으로 좌표가 주어졌을때, Euclid Distance를 기반으로 top-k nearest neighbors를 정의.
        
        $$
        N_i^k:=\{s_1, s_2, ..., s_k\}
        $$
        
    - 하지만 인접 픽셀들 간의 depth gaps가 final normal vector의 정확도를 해칠 수 있다는 점을 고려하여, regular term $|z_i-z_j| <\gamma$ 추가.
- **Least Square Fitting**
    - $n = (n_x, n_y, n_z)$ 를 계산하기 위해 neighbor point set $A \in \mathcal{R}^{k\times 3}$. $b\in \mathcal R ^{k\times 1}$ 를 먼저 계산.
        
        $$
        \mathbf{A}\mathbf{n} = \mathbf{b}, \text{s.t. } \|\mathbf{n}\|_2^2 = 1
        $$
        
        $$
        \mathbf{n} = \frac{(\mathbf{A}^T \mathbf{A})^{-1} \mathbf{A}^T \mathbf{1}}{\left\| (\mathbf{A}^T \mathbf{A})^{-1} \mathbf{A}^T \mathbf{1} \right\|_2^2}
        $$
        
    - k = 9 일때 좋은 결과를 얻을 수 있었다.

### Graph Construction

- 이 모듈의 목표는 similar semantic features를 가진 pixel들을 모아서 graph의 하나의 node로 변환하는것
- RGB와 Depth modality를 하나의 graph로 변환하여 fusion하는 것.
    - projection matrix 생성
    - features를 coordinate space에서 semantic space로 변환.
    - 두 modality로부터 node features aggregation
    - adjacency matrix 생성
- **Projection matrix**
    - 이는 2D feature map으로부터 도출 되며, 주로 coordinate space에 있는 pixel features를 semantic space에 있는 node features로 projection
    - 이 과정에서 coordinate space에서 비슷한 feature를 가진 픽셀들이 semantic space에서 동일한 node에 할당.
        
        $$
        P = F_g(X)
        $$
        
        - $P\in \mathcal R^{N\times H \times W}$, $X \in \mathcal R^{C \times H \times W}$
    - 가장 직관적인 구현은 feature map에 region growth method를 적용하는 것, 그러나 이는 미분 불가능하고 곱 연산이 가능하지도 않아서, CNN에 비해 오래 걸리며 back propagation 불가능.
        - region growth method: 기본 아이디어는 이미지에서 seed를 정하고 점점 growth 시켜서 하나의 region을 만드는 방식.
    - 저자들은 이전 연구들의 영감을 받아 assignment computing task로 간주하고 $F_g$ 를 1x1 Convolutional layer로 구현. 이는 layer의 input channel은 $C$, output channel은 $N$.
    - 이상적으로 변환된 node features는 한편으로는 coordinate space의 각 픽셀이 semantic space의 정확히 하나의 node에 할당되도록 해야하고, 다른 한편으로는 inter-node compact하고 intra-node distinct 해야한다. ← assignment 과정에서 semantic similarity와 positional similarity를 모두 고려.
    - 하지만 convolutional의 spatial-agnostic 특성 때문에 이는 어려운 task다.

    ![image.png](/assets/img/2026-03-03-p&f/image%202.png)
    
    - 저자들은 training이 진행됨에 따라 projection matrix가 부족해지는 경향을 반복 이는 위의 그림을 통해 확인 가능.
        - 초기 iteration에서는 blue dots 이미지가 전체에 균일하게 분포, 이는 각 픽셀이 하나의 node에 주로 할당되는것을 의미.
        - 하지만 점차 blue dots의 비율이 전체 이미지에서 급격히 감소하며, blue 영역의 픽셀들은 여러 노드에 할당되고 white 영역의 픽셀들은 어떤 노드에도 할당되지 않음. → Biased Assignemnt Problem이라고 notation함.
        - 이 현상은 일부 feature가 redundant해지고 다른 일부가 missing 되는 결과를 초래.
    - 이는 training이 진행됨에 따라 encoder-decoder 네트워크가 easy pixels을 정확히 분류할 수 있게 된다는것을 발견. 따라서 Graph Neural Network는 dfficiult regions에 집중.
    - 따라서 projection matrix의 또 다른 기능은 이러한 difficult pixel를 찾아내는것.
    - 이전 연구들에 영감을 받아, 저자들은 KL loss를 사용하여 projection matrix P와 uniform-distributed matrix(학습중 매 iter마다 새로 만들어짐, $P$ 와 같은 차원, 모두 같은 값) 간의 divergence를 최소화
        
        $$
        L_{\text{KL}} = \text{Kullback-Leibler}(P, I)
        $$
        
- **Feature Transformation**
    - GNN 단계에서 node feature dimension이 높아지면 계산량은 exponential 하게 증가한다는점을 고려해, feature transformation module을 사용해 dimension을 줄인다.
    - 두 modality(RGB, Normal)로부터 coordinate space에 있는 feature map을 입력으로 받아, transformed feature map을 출력
        
        $$
        Z = F_t(X)
        $$
        
    - 두 branch는 transformation은 동일 구조를 갖지만, 파라미터는 다르다.
    - 실제로 high-dimensional feature를 lower-dimensional feature로 변환하기 위해 linear function을 사용.
    - 계산 복잡도와 성능에는 trade off 관계가 있다.
- **Project and Fuse**
    - $Z$ 와 $P$ 를 입력으로 받아, projected and fused node feature를 출력.
    - Projection 부분에서는 간단한 matrix multiplication을 통해 projected node feature를 얻습니다.
    
    $$
    V = Z\cdot P
    $$
    
    - 3D branch에서도 유사한 feature transformation 과정을 적용, projection matrix는 RGB-D branch에서 생성된것을 그대로 상속.
    - 즉, 하나의 RGB-D 이미지와 depth map에 대해서는 단 하나의 projection matrix만 존재.
        - 2D와 3D의 homogeneity를 유지하여, 두 modality를 간단한 concatenation
        - 다른 한편으로는 RGB-D 이미지가 texture가 풍부하므로, RGB-D를 lead하고 depth를 supplement 하는 역할을 부여하기 위함.
    - Fusion 부분에서는 단순히 summation을 적용하여 최종 node feature matrix를 얻는다.
- **Adjacent Matrix Generation**
    - 기존 GNN 아이디어: adjacency matrix A = node feature similarity →semantic 관계만 고려.(위치 정보는 무시한다.)
    - pixel-wise semantic segmentation에서 위치 정보 역시 매우 중요한 역할을 한다고 주장하며, 그래프 추론 과정에서 이를 무시하면 성능이 저하.
    - 본 논문은 edge generation module에 $P$ 를 입력으로 받아 두개의 adjacment matrix를 출력
    - 각 adjacment matrix는 node similarities 의미적으로, 위치적으로 나타낸다. 이를 $A_s, A_l$ 이라고 표기하면, $\mathbb R^{N\times N}$ 이다.
    - Semantic-aware adjacent matrix의 경우, 기존 접근법을 따라 의미적 유사도에 기반해 edge 가중치를 생성
        - 이전 $V$  에서 계산된 feature embedding을 $v_i$ 라고 하면, i번째 노드와 j번째 node 사이의 semantic-aware 엣지 가중치는 내적을 통해서 구한다. $w_{s_{ij}} = v_i \cdot v_j^T$
    - Locality-aware adjacent matrix의 경우, projection matrix에 N개의 layer가 있고, 각 레이어가 $H\times W$ 픽셀을 현재 노드에 할당할 확률을 나타낸다는 의미라 여긴다.
    - 각 $H\times W$ 크기의 2D 행렬이 해당 노드의 정보를 나타낼 수 있으며, 전체 $P$ 는 모든 노드의 위치 정보를 표현할 수 있다고 주장한다. 본 논문은 두가지 접근법을 제안한다.
        - 직관적인 접근법은 투영 행렬을 그 전치 행렬과 바로 곱한는 것. 두 노드 간의 위치적 유사도를 반영할 수 있다.
        - 위치 정보를 더 시각화 가능한 형태로 모델링하기 위해, 각 노드의 위치 중심 좌표를 나타내는 행렬 $M \in \mathbb R ^{N\times 3}$ 을 도입.
        
        ![image.png](/assets/img/2026-03-03-p&f/image%203.png)
        
        - 그러나 이 접근법은 시간이 많이 소요되며, back propagation은 불가능.
        - 따라서, $P$ 에 linear transformation을 적용하여 $M_c \in \mathbb R^{N\times 3}$ 을 생성.
        - $L_{MSE} = MSE(M_g, M_c)$ 를 사용하여 변환된 좌표와 GT 간 거리를 최소화.
    - 결과적으로 locality-awayre의 edge 가중치는 각 좌표간의 Euclidean distance를 이용해 얻는다.
    - i 번째 노드의 위치 인코딩을 $(x_i, y_i, z_i)$ 라고 하면, i 번째와 j번째 노드 사이의 locality-aware 엣지 가중치는 다음과 같이 정의 된다.
        
        $$
        w_{l_{i, j}} = \frac{1}{\text{Euclid}(i, j)}
        $$
        

### Graph Neural Networks

- Graph Neural Networks Module은 fused node features $V$ 와 adjacent matrix $E$ 를 입력받아 updated node features 를 출력.
- 이 모듈의 목적은 fused graph 상에서 feature learning을 수행하는 동시에, semantic space에서의 관계와 coordinate space에서의 positional attributes를 모두 caputre 하는 것.

$$
\tilde V = F_n(V, W)
$$

- 여기서 $F_g$ 는 Graph Reasoning 또는 Graph Convolution. 실제 구현에서는 Graph Convolution Networks를 채택. neightbor nodes를 기반으로 node features를 update.
- node embedding $h_v$ 와 neightbors embedding $h_u$ 에 대해, graph convolutional layer는 feature aggregation 연산을 수행하여 updated embedding $\tilde h_v$ 를 출력.
- node 자체의 features를 보존하기 위해, node 자신과 neighbor들에 대해 서로 다른 message computation을 수행.

### Graph Re-projection

$$
m_v = W_s(h_v)
$$

$$
m_u = AGG[(W_N(h_u)]
$$

$$
\tilde h_v = \sigma(SUM([m_v, m_u]))
$$

- Updated node features $V_{new} \in \mathbb R^{N\times D}$ 를 다시 coordinate space 으로 되돌림
- Projection matrix $P$ 재사용 → Re-projection matrix $Q = P^T = \{q_1, ..., q_N\} \in \mathbb R^{H*W \times N}$
- Updated feature map $\tilde Z = Q\cdot \tilde V$
- Feature dimension 조정 $\tilde X = \tilde Z \cdot T$
- Cross Entropy Loss 사용 $L_{CE} = CrossEntropy(\tilde X, Y)$

### Loss Function

- **총 Loss 구성**

$$
L = L_{CE}+\alpha \cdot L_{KL} + \beta L_{MSE}
$$

## Experiments

- Datasets: NYUv2-40, SUN RGB-D
- Implementation Details
    - Backbone: DeepLabV3+ResNet50
    - Optimizer: Adam(lr=0.01, weight decay=0.0002)
    - hardware: RTX3090 GPU, batch size=4
- **Ablation Study**
    - 2D branch (RGB baseline: DeepLabV3+ ResNet50):
        - Biased-Assignment 완화: KL-Divergence Loss → +1.2% mIoU
        - Assignment type: soft → hard → +0.2% mIoU
        - 둘 다 결합 → +1.3% mIoU
        - Edge weight 생성 방식 비교:
            - Projection matrix 직접 곱 → competitive
            - Region centroids (제안 방법) → 최고 mIoU
        - GNN 선택: Graph Reasoning → GCN layer로 변경 → +0.5% mIoU
        - Inference time 고려 시 projection matrix 방식이 파라미터 적고 경쟁력 있음
    - Fusion branch (RGB-D):
        - Baseline: 두 DeepLabV3+ 병렬 → 평균 (summation)
        - Summation vs Concat: summation이 더 좋음 (mIoU ↑ + 파라미터 ↓)
        - 3D input 비교: depth map → normal map / HHA map → competitive / 더 나음
        (depth map 직접 쓰면 개선 제한적 → CNN이 depth 경향성 잘 못 잡음)
