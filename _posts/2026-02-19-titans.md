# Titans: Learning to Memorize at Test Time

## Introduction

- Transformers의 핵심 구성요소 attention 모듈은 associative memory blocks로 작동하며, key-value associations를 저장 query와 key간의 pairwise similarity를 계산하여 이를 검색한다.
- self-attention 메커니즘은 모든 토큰끼리 유사도를 계산한다. 이로 인해 시간복잡도, 메모리 복잡도는 O(N²)를 갖는다. 이러한 특성은 real world에서는 context window가 매우 커질 수 있으므로, downstream tasks에서 Transformer의 적용이 어려워진다.
- Transformer의 scalability문제를 해결하기 위해 최근 연구들은 다양한 linear Transformer를 설계.
    - attention softmax를 kernel function으로 대체. → memory consumption을 크게 줄인다.
        - softmax는 $A = softmax(QK^T)V$ . 여기서 중요한점은 $QK^T$ 즉,  N×N attention matrix를 반드시 계산해야한다.
        - linear attetnion은 $A = \phi(Q)^T\phi(K)V$(조건 $\phi(x, y) =\phi(x)^T\phi(y)$ 분해 가능 커널.) 즉, 결합법칙 사용 가능 $A=\phi(Q)^T(\phi(K)V)$→ 메모리 사용량 O(d²).
            - 간략하게 설명하면, $\phi(K)V = \sum \phi(q)v^T$ → 메모리 사용량이 N과 무관한 O(d²) 이 된다. ($K,Q, V \in \mathbb{R}^{N\times d}$)
- 그러나 linear Transformers는 efficiency와 긴 context로의 확장성 측면에서는 장점이 성능면에서 경쟁력이 없다. 이는 kernel trick으로 인해 모델이 matrix state를 갖는 RNN과 같은 구조를 갖게 되었기 때문이다( $\phi(K)V = \sum \phi(q)v^T$).
- 이렇듯 대부분의 현존하는 아키텍쳐들은 generalization, length, extrapolation, reasoning과 같은 문제에서 어려움을 겪는다. 이러한 아키텍쳐들은 뇌에서 영감을 받았지만, 다음과 같은 요소들이 결여되어 있다.
    - 학습 과정에서 중요한 구성 요소- 예를 들어 short-term memory, long-term memory, meta-memory, 현재 context에 대한 attention
    - 이러한 구성 요소들이 협력적 작동하면서도 상호 연결된 시스템으로 구성되는방식
    - 데이터로부터 능동적으로 학습하고 과거 history의 abstraction을 기억하는 능력
- 저자들은 서로 구별되면서도 여러 모듈로 구성되어야 하며, 각 모듈은 학습 과정에서 중요한 특정 구성 요소를 담당해야 한다고 주장한다.

### Memory Perspective

- 대부분의 기존 아키텍처들은 memory를 입력에 의해 발생하는 neural update로 간주하고, learning을 특정 objective하에서 효과적이고 유용한 memory를 획득하는 과정으로 정의한다.
- 이 관점에서 본 RNN은  vector-valued memory module $M$ 을 가지는 모델로 정의할 수 있다.
    1. $f(M_{t-1}, xt)$ 를 사용하여 memory를 업데이트
    2. $g(M_t, xt)$ 를 사용하여 해당 입력에 대응하는 memory를 검색
- 이 관점에서 본 Transformer는
    - key와  value를 memory에 추가함으로써 memory를 업데이트(non compressed)
    - query와 key 벡터 간의 유사도를 계산하여 해당 memory를 검색하고, 이를 value vector에 가중치를 부여하여 출력을 생성
- 이런 관점에서 본 Transformer와 linear Transformer의 차이점은 memory 구조와 memory update 방식에 있다.
    - linear Transformer는 matrix 방식으로 압축 후 선형적으로 업데이트 ↔ Transformer는 압축없이 유지 후 병렬적으로 retrival
- linear Transformer와 RNN의 차이는 memory 구조에 있다.
    - linear Transformer는 matrix valued ↔ RNN은 vector valued
- 저자들은 이러한 관점에서 3개의 질문을 내놓았다.
    - memory관점에서 어떤 구조가 최적인가?
    - memory update는 어떤 방식이 적절한가?
    - memory retrival process는 어떤 방식이 적절한가?
- 인간의 메모리 관점에서 이는 합일된 프로세스도 한개의 function도 아니다. 메모리는 여러개의 독립된 모델들이 연결된 모듈이다. 이런 사실속에서 저자들은 또 질문을 내놓는다.
    - 어떻게 독립된 연결된 모듈들을 설계할것인가?
- 인간의 뇌는 과거를 추상화한 후, 저장한다. 과거의 장기적 history를 저장하기에, vector, matrix 만으로는 충분하다라고 가정하는것은 단순한 접근일 수 있다.
    - 긴 과거를 효과적으로 저장/기억하기 위한 deep memory module이 필요한가?

### Contributions and RoadMap

- 저자들은 위의 질문들을 대답할 수 있는 모듈을 설계한다. 또한, 실제 아키텍처에 어떻게 통합할 수 있는지에 대해서도 논의한다.
- 저자들은 모듈을 인간의 뇌에 기반해 기대치 이상인 이벤트들을 더욱 잘 기억할 수 있도록 계획한다. 이를 위해, associative memory loss에 대한 gradient(surprise)를 측정한다.
- 또한 제한된 memory를 위해, surprise 양에 의존하는 decaying mechanism을 제안. 흥미롭게도, 이 메커니즘은 mini-batch gradient descent, momentum, weight decay를 사용하는 meta neural network 최적화와 동등함을 보인다.
- 또한 mini-batch gradient descent를 더 많은 matmul 연산으로 tensorization 하는 방법을 기반으로, 빠르고 병렬화 가능한 방식으로 학습시키는 알고리즘을 제안.
- Titans라는 모델은 아래의 세개의 hyper-head로 구성된다. 또한 1)context 2)layer 3)gated branch를 통해 개념증명을 한다.
    - Core: short-term memory를 포함하는 모듈, 데이터 처리의 주요 흐름을 담당(window size를 가진 attention 사용)
    - Long-term Memory: neural long-term memory module, 긴 과거 정보를 저장/기억하는 역할
    - Persistent Memory: 입력 데이터와 독립적인 학습 가능한 파라미터 집합, 특정 task에 대한 지식을 인코딩
- 결과, Titans는 동일한 context window를 사용하는 Transformer보다 나은 성능을 보였다. 또한 Titans는 Transformer와 달리 2M이상의 context window 크기까지 확장 가능하다.

## Learning to Memorize at Test Time

### Long-term Memory

- neural long-term memroy module을 설계하기 위해서는, 과거 history 추상화를 자신의 파라미터에 인코딩할 수 있는 모델이 필요.
- neural network에서 training data를 기억하도록하는것은 일반적으로 바람직하지 않은 현상으로 여겨진다. 따라서 저자들은 test time에서 데이터 기억하고 잊는법을 배우는 online meta-model이 필요하다. 이 구조에서는 모델이 memorization 가능한 함수를 학습하지만, training data에 overfit하지 않고 test-time generalization이 향상된다.
- 저자들은 과거의 정보 $x_1,..., x_{t-1}$ 를 long-term neural memory module $\mathcal{M}_t$ 에 압축한다.
- surprising event(입력에 대한 loss gradient크기가 큰것)가 더 잘 기억되는것을 고려해서 다음과 같이 정의한다.

$$

\begin{equation*}
\mathcal{M}_t = \mathcal{M}_{t-1} - \underbrace{\theta_t \nabla \ell(\mathcal{M}_{t-1}; x_t)}_{\text{Surprise}}.
\end{equation*}

$$

- 그러나, 위와 같은 수식은 큰 surprise가 일어난 경우, 이후 중요한 정보를 손실 할 수 있다. 왜냐하면, surpriseing events 이후, gradient가 급격하게 작아지기 때문이다. 그렇기에 저자들은 surprise metric을 (1) past surprise, (2) momentary surprise 으로 나눈다. 아래의 구조는 momentum이 있는 gradient descent와 유사하다.
    
    $$
    \begin{align*}\mathcal{M}_t &= \mathcal{M}_{t-1} + S_t, \\S_t &= \underbrace{\eta_t S_{t-1}}_{\text{Past Surprise}} - \underbrace{\theta_t \nabla \ell (\mathcal{M}_{t-1}; x_t)}_{\text{Momentary Surprise}}.\end{align*}
    $$
    
    - $\eta_t$ 는 data-dependant decay. context가 바뀌면 → 0, 유지되면 → 1
- surprise는 위의 수식과 같이 loss function 기반이다.
- 저자들은 associative memory를 사용한다.
    - associative memory란 Key를 주면 그에 상응하는 기억을 떠올리는것을 의미한다. Transformer, Linear Transformer도 같은 방식으로 학습된다.
    - attentaion: $softmax(QK^T)V$ → query와 비슷한 key를 찾고 그에 대응하는 value를 가중합으로 반환.
    - linear attention: $M = \sum \phi(k_j)v_j^T$ → 모든 key value를 행렬 형태로 저장한것.
- 본 논문은 아래와 같이 정의한다.
    
    $\ell(M_{t-1}; x_t) = \|M_{t-1}(k_t) - v_t\|_2^2$ ( $k_t = x_tW_K, v_t = x_tW_V,(W_K, W_V \in \mathbb{R}^{d_{in}\times d_{in}})$)
    
    - 즉, memory가 key → value 매핑을 학습하도록 만든다.
    - memory 학습은 inner-loop(M의 파라미터 업데이트)에서 이루어진다.
- 방대한 양의 sequences를 저장하기 위해서는 Forgetting mechanism은 중요하다. 저자는 adaptive forgetting mechanism(더 이상 필요가 없을 시 잊기)를 사용한다.
    
    $$
    M_t = (1 - \alpha_t)M_{t-1} + S_t
    $$
    
    $$
    (S_t = \eta_t S_{t-1} - \theta_t \nabla \ell (M_{t-1}; x_t)
    $$
    
    - $\alpha_t$ 는 gating 역할을 한다.
        - $\alpha_t$ → 0: 과거 유지
        - $\alpha_t$ → 1: memory 초기화
- 저자들은 Memory Architecture를 단순히 MLP(L_M ≥ 1)를 채택한다. 이는 이후 Section에서 실제로 더 효과적임을 보인다.
- Memory Retriving 은 weight update 없이 forwar pass를 수행함으로 얻을 수 있다.
    
    $$
    y_t = M^*(\mathbf{q}_t)
    $$
    

### How to Parallelize the Long-term Memory Training

- 저자의 long-term memory module 설계는 associative memory loss funciton에서 momentum 과 weight decay로 최적화하는 meta model을 학습하는것과 동일하다. 하지만, 실제 구현에서 사용하기 위해서는 병렬화해야한다.
- 시퀸스를 크기가 b ≥ 1인 chunk로 분할시 아래와 같이 사용할 수 있다.
    
    $$
    M_t = (1 - \alpha_t)M_{t-1} - \theta_t \nabla \ell (M_{t-1}; x_t) = \beta_t M_0 - \sum_{i=1}^{t} \theta_i \frac{\beta_t}{\beta_i} \nabla \ell (M_t'; x_i)
    $$
    
    - $t' = t - \text{mod}(t,b)$
    - $\beta_i = \prod^i_{j=1}(1-\alpha_j)$
    - 첫번째 batch, $t = b, t' = 0$ 인 경우를 고려하면, $M_t = W_t$ 가 linear 인 경우 아래와 같이 쓸 수 있다.
        
        $$
        \nabla \ell (W_0; x_t) = (W_0 x_t - x_t) x_t^\top \Rightarrow \sum_{i=1}^b \theta_i \frac{\beta_b}{\beta_i} \nabla \ell (W_0; x_i) \\= \Theta_b \mathbf{B}_b (W_0 X - X) X^\top
        $$
        
    - $\Theta_b = diag([ \theta_1\  \theta_2 \ ...\ \theta_b ])$
    - $\bold{B}_b = diag([\frac{\beta_b}{\beta_1} \frac{\beta_b}{\beta_1}\  ... \ \frac{\beta_b}{\beta_b}])$
- momentum항은 다음과 같다.
    
    $$
    S_t = \eta_tS_{t-1} -\theta_t u_t
    $$
    
    - $u_t = \nabla \ell(\mathcal{M_{t'}, x_t})$
    - 모든 $u_t$ 는 동시에 계산 가능하다. 따라서 위 식은 $u_t$ 를 입력으로, $S_t$ 를 hidden state로 $\eta_t$ 를 input-dependent transition vlaue로 갖는 linear-recurrence가 된다.

**Parameters as the Function of Chunks**

- $\alpha_t, \theta_t, \eta_t$ 를 $x_t$ 에 의존하게 만드는 대신, 각 chunk에 대한 함수로 정의 할 수 있다.
- 표현력은 일부 감소, 학습속도는 더욱 빨라질 수 있다. ← 각 chunk 내 동일한 값 사용.
- 즉 위와 같이 사용하면 $\Theta$ 를 스칼라로 지정 가능하며, 계산량이 줄어든다.
- 본 논문에서는 다루지 않고, 이는 향후 연구 주제가 될 수 있다.

### Persistent Memory

- 저자의 long-term memory는 contextual memory이다. 즉, 출력이 전적으로 context에 의존한다는 의미.
- persistent memory를 추가해 learnable 하지만, input-independent한 파라미터 집합을 추가하여, task-related memory로 작동하도록한다. 아래를 통해 세가지 관점에서 persistent memory를 설명한다.
- $N_P$ ≥ 1 일때, learnable 파라미터 $P = [p_1, p_2, \ ... \ p_{N_P}]$ 를 사용하여 시작부분에 append 한다.
    - $x_{new} = [p_1 p_2 \ ...\ p_{N_P} ] || x$ 여기서 || 는 concat을 의미한다.
- **Memory Perspective**
    - 앞서 설명했듯, neural long-term memory는 contextual memory이며, 이는 input dependent하다.
    - 효과적인 memory system은 input-dependent한 파라미터도 필요하다. 이는 task knowledge의 추상화를 저장하기 위함.
    - 어떤 task를 숙달한다는 것은 그 task를 어떻게 수행하는지에 대한 지식을 기억하는것을 의미하며, persistent memory 파라미터는 이러한 지식을 저장하는 역할을 한다.
- **Feedforward Network Perspective**
    - 기존 Transformer architecture에서 attention module 이후에는 fully connected layers가 존재.
    - 이 fully connected layers는 data-independent 파라미터를 가지면서 attention weights와 유사한 역할을 한다는것이 알려져있다.
    - 이때 Sukhbaatar, Grave, et al. (2019)는 fully connected layer에서 ReLU를 Softmax로 대체하면 attention-like weights를 얻을 수 있으면, 이때 weights는 data-independednt하다는것을 보였다.
        
        $$
        FFN(x) = W_v\text{Softmax}(W_Kx)
        $$
        
    - 여기서 $W$attention 모듈의 $K, V$ 행렬과 유사한 역할을 한다.
    - 따라서 Persistent memory의 weights 역시 동일한 기능을 할것으로 기대된다. 이를 sequence의 앞부분에 두면 input-independent attention weights를 갖는 효과를 낸다.
- **Technical Perspective**
    - Causal mask를 사용하는 attention은 sequence의 초기 token에 대한 implict bias를 갖는다.
    - 그 결과, attention weights는 종종 초기 token에 과도하게 집중하게 되며, 이는 성능 저하로 이어질 수 있다.
    - Technical 관점으로 보면, sequence 시작 부분에 learnable한 파라미터를 추가할 시 완화할 수 있다. 즉, attention weights를 보다 효과적으로 재분배할 수 있다.

## How to Incorporate Memory

- 아직 해결되지 않은 질문이 남았는데, 딥러닝 아키텍처에서 어떻게 효과적이고 효율적으로 메모리를 통합할 수 있는가?
- 저자는 Transformer의 associative memory는 컨텍스트 윈도우가 제한되어 있기 때문에 이를 limited context window 내에서 동작하는 short-term memory 모듈로 해석한다. 반면 데이터로부터 지속적으로 학습하고 그 정보를 가중치에 저장할 수 있는 저자들의 모델은 long-term memory 역할을 수행할수 있다.
- 다음으로는 Titans모델에 3개 variants의 아키텍처들을 보여주고 , long context에서 이 변수들을 변화시키면서 어떤 trade-off 관계를 갖는지 소개한다.

### 1. Memory As a Context (MAC)

![image.png](/assets/img/2026-02-19-titans/image.png)

- 위의 그림과 같이 저자들은 메모리를 현재 정보에 대한 context로 다룬다.
- 즉, 길이가 긴 시퀸스 $x \in \mathbb{R}^{N\times d_{in}}$ 주어지면, 이를 고정 크기의 $S^{(i)}(i=1, ..., N/C)$ 로 나눈다.
- $S^{(t)}$ 를 현재 컨텍스트로 보고, 이전 segment를 historical information으로 간주한다. $S^{(t)}$ 가 들어오기 직전의 장기 메모리를 $\mathcal{M}_{t-1}$ 이라고 하고, 현재 입력 컨텍스트를 query로 사용하여 메모리 $\mathcal{M}_{t-1}$ 에서 retrive.
    
    $$
    h_t = \mathcal{M}^*_{t-1}(q_t)
    $$
    
    - $q_t = S^{(t)}W_Q$
    
    $$
    \tilde{S}^{(t)} = \left[ p_1 \ p_2 \ \dots \ p_{N_p} \right] \Vert h_t \Vert S^{(t)}
    $$
    

$$
y_t = \text{Attn}(\tilde{S}^{(t)})
$$

- 이후, $y_t$ 를 이용해 long term memory module을 update하고(forward pass), output을 얻는다.

$$
\mathcal{M}_t = \mathcal M_{t-1}(y_t)
$$

$$

o_t = y_t \otimes \mathcal{M}_t^*(y_t).

$$

- 위의 아키텍쳐는 3가지 장점을 갖는다.
    - Attn은 historical context와 current context를 모두 갖고 있으므로, 주어진 current data에 대해 long-term memory information의 필요한 정도를 스스로 결정.
    - Attn module은 long-term memory가 current context로부터 유용한 정보만 저장하도록 돕는다. 즉, 각 segment의 모든 token이 유용한것이 아니며, memory capacity를 더 효율적으로  관리하도록 돕는다.
    - Test time에서의 동작은 아래와 같다.
        - Persistent memory parameters는 task에 대해 knowledge를 encode하고 있으므로 fixed상태로 유지된다.
        - attention module weights는 in-context learner로 동작한다.
        - long-term memory module은 test time에도 계속 learning을 수행한다.
        
        즉, neural memory의 weights는 long past의 abstraction을 encode하고 있기 때문에, test time에도 해당 weights를 계속 update한다.
        

### 2. Gated Memory(MAG)

![image.png](/assets/img/2026-02-19-titans/image%201.png)

- 위의 variant는 한 브랜치에서는 입력 데이터를 직접 사용하여 long-term memory를 update 하고, 다른 브랜치에서는 sliding window attention(SWA)를 사용한다.
    - SW-Attn은 self-attention의 제한 버전이다. 핵심 아이디어는 각 토큰이 전체를 보는게 아닌, W개 토큰만 본다.

$$
\tilde{x} = [p_1 \ p_2 \ \dots \ p_{N_p}] \ \| \ x
$$

$$
y = \text{SW-Attn}^* (\tilde{x}) ,
$$

$$
o = y \otimes \mathcal{M}(\tilde{x})
$$

- 여기서 SW-Attn은 prefix가 된 sliding window attentnion을 의미한다.  Memory as a Context 설계와 달리 Segmentation을 진행하지 않는다. 표기의 단순화를 위해 $\mathcal{M}(\tilde{x})$ 는 시퀸스 모든 token에 대한 계산 결과의 최종 output을 의미한다.
- 위의 식에서 ⊗는 임의의 non-linear gating이 될 수 있다.
- 실험에서는 $y$ 와 $\mathcal{M}(\tilde x)$ 를 learnable한 vector-valued로 normalized 한 뒤, non-linearity gate를 적용.
- 이 구조에서 sliding window attention은 short-term memory, neural memory module은 fading memory로 동작.
- 이 아키텍처는 head들의 구조가 서로 다른 multi-head architecture로 해석할수도 있다.
    - 한 head는 local dependency 담당
    - 다른 head는 global fading memory 담당

### 3. Memory as a Layer (MAL)

![image.png](/assets/img/2026-02-19-titans/image%202.png)

- 마지막 위의 구조는 neural Memory As a Layer (MAL)를 사용하는 방식.
- 이러한 architecture는 일반적인 형태로 hybrid models가 recurrent models와 full attention 또는 sliding window attention을 sequential하게 stack 하는 구조와 유사하다.

$$
\tilde{x} = [p_1 \quad p_2 \quad \dots \quad p_{N_p}] \quad || \quad x
$$

$$
y = \mathcal{M}(\tilde{x})
$$

$$
o = \operatorname{SW-Attn}(y)
$$

- 단점으로는, 모델의 표현력이 각 layer에 의해 제한된다는 점. 따라서 attention module과 neural memroy module이 가진 complementary 데이터 처리 능력을 충분히 활용하지 못한다는 점.
- introduction에서 설명되바와 같이 메모리 관점에서 보면, 메모리 시스템의 각 구성요소는 다른 구성 요소와 독립적으로 동작해야 한다. 따라서 long-term memory module은 short-term memory가 없더라도 강력한 모델이어야한다.(NLL은 attention이 없이도 잘 동작되어야한다.)

### Architecture Details

- 모든 block에서 residual connection을 사용한다.
- 구현에선는 query, key, value를 계산할 때 비선형 함수 SiLU() 사용.
- query, key는 L2 norm으로 정규화한다.
- **Convolution**
    - 최근의 modern linear recurrent models을 따라, 각 query, key, value projection 이후에 1D depthwise-separable convolution layer를 추가. ← 성능에 큰 영향 없지만, 성능 효과가 관찰되었으며 계산적으로 효율적이다.
- **Gating(정보를 얼마나 통과시킬지 조절하는 메커니즘)**
    - output projection 이전에 normalization과 linear layer 기반 gating을 적용.
- Theorem 4.1
    - 기존 모델들은 TC 0(Merrill et al., 2024)에 제한되는 반면 Titans는 TC 0(이게 머임)을 넘어서는 문제들을 해결할 수 있다.
    
    → Titans가 기존 모델들보다 이론적으로 더 높은 표현력을 가진다는것을 의미한다.
